## 本卷核心

- 制度层：OAA把学力、身体、灵活、社会贡献与综合评价公开化；跨年级搭档考试把一年级纳入二年级的退学风险与点数竞争。
- 月城/White Room层：月城要求匿名潜入者在四月使清隆退学。
- 班级/关系层：铃音建立501+操作安全线并统筹搭档；清隆以数学满分主动放出一部分能力，随后借铃音、平田、惠与组员网络处理班内信任成本。
- 低年级层：宝泉以暴力、金钱和自刺嫁祸推进，七濑同时参与、制止并审判清隆，天泽在料理、削皮刀与清隆房间/关系施压阶段中保持危险且非单一敌我定位。
- 恋爱层：惠与佐藤当场止裂但未完全修复；天泽的监视/性挑衅把惠带到两千万悬赏入口，正文只到清隆作出说明决定。

### OAA

- 茶柱称OAA由南云提案、学校批准；这是教师转述的制度来源。
- OAA公开四项基础能力（学力、身体能力、灵活思考力、社会贡献）及由四项计算的综合能力；不是“五项基础能力+综合”六项结构。清隆判断新生灵活思考力等数值可能尚不可靠，这不是系统自认。

### 个人赛与退学门槛

- 每名学生考5科，每科100分，个人满分500；跨年级两人配对，配对满分1000。
- 规则表`741-776`字面写“配对合计低于500”时二年级退学、一年级未来3个月无个人点数。
- 但`826-870`清隆按“500以下会退学/搭档至少拿1分”推演，`905-957`铃音明确采用501+安全线，`5752-5842`仍以501处理。四件套统一保留这项译文/叙述内部冲突：规则表字面`<500`，人物全程操作口径`501+`；不得无注释擅自统一。
- 被校方认定故意错答/操纵成绩的该名学生，无论属于一年级或二年级都退学；强迫第三者故意低分者也退学。规则没有写成无辜搭档随操分者一并退学。
- 规则没有“违规搭档被退学后另一人自动及格”的保障；那只是清隆希望存在但发现未给的安全网。

### 配对流程

- 双方同意并在OAA登记后不可解约；退学、重病等不可抗力例外。
- 每天只能向1人申请；申请未被接受则24小时后重置。正文没有说明明确拒绝与未回应存在不同的重置速度。
- 截止仍未配对者于考试日8点随机配对，并将两人总分扣5%。
- 多出的3名一年级单独考试，个人分数乘2后同样扣5%。

### 排名与奖励

- 年级内班级赛按本班学生及其所有搭档成绩的平均值排名，班级奖励依次`+50/+30/+10/+0cl`。
- 个人前5组每人`100,000pr`；前30%每人`10,000pr`。正文未说明两个个人奖励档是否叠加，不能自定。
- 每班一年级初始`800cl`只是七濑转述司马克典的说明；不是本场校方表格。
- 清隆推演月城可利用规则让White Room学生低分拖退自己。

### 月城、匿名White Room学生与规则入口

第三人称旁白确认匿名听者是15岁White Room受训学生 → 月城交付四月退学任务 → 匿名学生确认不得显眼行动 → 月城用最高杰作话术刺激，旁白直述其点燃反抗心的意图、情感误判与White Room灌输/憎恨结构 → OAA与搭档规则公布 → 清隆推演零分拖退漏洞 → 月城在会客室声称潜入者已完成伪装、违令并可能因嫉妒行动 → 匿名者独白自述第五期压力、观察欲和杀意。

### 铃音的搭档策略

一之濑交流会以信任吸引新生 → 铃音承认无法复制其社交，退出交流会 → 锁定全员缺席的一年D，先立无人退学/不打金钱战 → 清隆/铃音推演宝泉高价策略 → 铃音再立第三名以上目标 → 天泽以料理条件提出须藤配对 → 七濑路线先获讨论、后因宝泉拒绝而破裂 → 宝泉夜后两D合作落地。

商城交涉中只有白鸟本人报出`500,000pr`；加贺、三神只是与其共同不接受低价，并因畏惧宝泉而拒绝被另行召集。

### 天泽料理—削皮刀—房间链

天泽自报学力A/候选身份 → 提强者/格斗验证 → 清隆与铃音虚张须藤最强并接受，天泽不实战而改料理 → 铃音谎称清隆擅长料理并争取时间 → 天泽要求清隆独自采购 → 购买附刀套削皮刀（当时只作料理） → 天泽随清隆第一次进入401房、在房内看电视并监看测试，铃音借须藤手机与隐藏耳机远端指导清隆完成冬荫功 → 天泽第二次因发圈来访，经惠同意、清隆解锁后获准进入401房并搜索，取刀动作未直证 → 宝泉场由清隆重建削皮刀/指纹/天泽链 → 卷末SS065与正文呈现天泽监视惠、预藏食材并第三次来到401房，入室后挑衅。

### 七濑的协作、试探与悬赏

清隆拟随机接触一年级但尚未实施 → 七濑有意先拦截（SS060直证） → 清隆先提两D合作，七濑赞同并安排讨论 → 第一次图书馆会面由日和推荐隐蔽位置后离开 → 第二次会面日和提前请人空出座位 → 七濑报告宝泉控制/15组并假提暗中领导与切割 → 铃音拒绝，清隆判断这是测试 → 七濑承诺带宝泉、铃音提KTV并由她转达 → 谈判失败 → 宿舍后方七濑拒绝继续协助宝泉、遭掌掴但仍在场 → 伤后自述参与两千万任务及“不适合学校”判断。第一次图书馆会面里，铃音另提到自己当天也向一年D班的「梶原同学」问过同一问题；正文未给其回答、全名或性别。

宝泉夜后，茶柱与真嶋共同掩护清隆左手重伤的真实情形，使伤情未向更多学生曝光；这条后见直证不说明真嶋知道削皮刀骗局、两千万悬赏或White Room。

清隆随机接触前确认一年A的栗原春日、小西彻子学力优秀且首日已配对；这是OAA/现场信息。惠的搭档则只以一年B“岛崎同学”出现，学力B-；该人不能与清隆同年级的岛崎一庆合并。

### 宝泉自刺嫁祸与两项条件

KTV对等合作/保护点谈判破裂 → 尾随并追加点数 → 宿舍后方暴力升级，须藤败北、铃音迎战 → 七濑拒助 → 宝泉持削皮刀逼近 → 清隆先判断刀刃目标不是自己 → 宝泉自刺意图开始时，清隆以左掌接刀 → 清隆重建指纹与天泽链 → 提出两D合作、宝泉与清隆配对两项条件。
