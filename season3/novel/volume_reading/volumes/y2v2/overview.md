## 本卷核心

Y2V2是全学年无人岛考试的战前组队卷，不是岛上本战。

- 制度层：学校先公布初始同年级组、岛上大组、奖罚、救济与八类卡片；大量细则仍明确只是一部分，不能用后卷规则倒灌。
- 二年级层：铃音班在独占高收益与跨班分散风险之间选择；A/C合作、龙园班招揽、清隆单人隔离与高圆寺自由契约同时形成。
- 一年级层：八神、天泽、七濑、椿、宇都宫与宝泉分别提供证言、请求、试探或计划，但“南云/月城悬赏链”“波田野退学责任”“White Room身份”都未在本卷完成独立核验。
- 关系层：清隆选择优先准备惠的救济资金；这既是男友保护，也是风险管理。

### 日程与规模

- `7/19`操场集合、乘车赴港并登船；`7/20`考试开始并交付物资。
- `8/3`考试结束，在船内公布名次并支付报酬；八月个人点数会先套用无人岛结果再发放。
- `8/4-8/11`为八天七夜巡航假期，`8/11`返校解散。
- 三个年级同场竞争；低年级的报酬/惩罚会有平衡调整。校方当场只公布规则的一部分。

### 初始组、岛上大组与脱队

- 出发前只能在同年级内组成初始小组，不得跨年级。上限为一年级4人、二年级3人、三年级3人。
- 二年级初始组允许：单男、双男、三男、单女、双女、三女、一男两女；不允许两男一女或一男一女。
- 初始组一旦成立不能换组。正式考试中可与同年级其他小组合并成最多6人的大组；4人以上时女性至少占一半。
- 持“增员”的学生可作为第7人加入，且不受男女比例影响。因此“最多30人退学”只是清隆在增员卡公布前按五组×六人所作的即时估算，不是最终制度上限。
- 组员因伤病脱队时，剩余组员可继续；脱队者仍随该组最终名次处理。单人一旦脱队，小组即失去资格。

### 前段奖励、班点转移与后段惩罚

- 第一名：`300cl`、组员每人`1,000,000pr`、保护点1。
- 第二名：`200cl`、组员每人`500,000pr`。
- 第三名：`100cl`、组员每人`250,000pr`。
- 前50%组员每人`50,000pr`；前70%组员每人`10,000pr`。原表均写“包含第一至第三名”，但未进一步说明两档是否彼此累加，不能擅自结算。
- 前三名班点按小组内所含班级数均分并四舍五入；不是按人数分配。
- 若前段与对应后段小组来自不同年级，前三合计600班点从倒数三组所属年级转移；不足由学校补足。
- 若来自同一年级，对应倒数第一/第二/第三组所含班级支付`100/66/33cl`；若倒数组混合四班，降为`75/50/25cl`。
- 倒数五组成员退学。每个受罚小组的救济总额固定`6,000,000pr`并按组员人数均摊；每个人可凭自己那一份独立自救，不因其他组员余额不足被连坐。
- 救济点必须在登船前已在本人手机账户内；考试开始后不能再借入。

### 八类卡片

| 卡片 | 明示效果 | 门禁 |
| --- | --- | --- |
| 领先 | 开考时可用点数变为1.5倍 | 只按其明示资源解释。 |
| 追加 | 持有者所得个人点数报酬变为2倍 | 不自动改变班点。 |
| 减半 | 持有者受罚时支付的个人点数减半 | 卡名固定为“减半”，不是“半价”。 |
| 搭顺风车 | 额外得到开考时指定小组一半的个人点数报酬 |  |
| 保险 | 因身体不适失格时获一天恢复缓冲 | 不正当行为等失格不适用。 |
| 增员 | 持有者可作为大组第7人 | 开考后生效，不受男女比例影响。 |

- 每名学生随机获得一张。卡片只能在同年级跨班交易，同班之间不能交易；第一次转手后锁定，不能再转手。
- 同类卡效果不叠加；三种特殊卡“增员、无效、试炼”每学年各只有一张。

### 七濑开场与期限

七濑问候并为先前行动道歉 → 称“针对清隆的特别考试”会持续到第二学期开始 → 报告一年级五月末考试、各班大致结果与宝泉近况 → 清隆压住追问参与者的念头 → 二人分别说会不留遗憾后告别。

### 高圆寺与牺牲组两条未执行方案

高圆寺确认单人病退也须`6,000,000pr` → 请求加入清隆组，被拒后称另想办法。与此同时，清隆/铃音识别“五个牺牲组+班级筹款救回”的规则漏洞 → 算出救济合计`30,000,000pr`且另有班点代价 → 放弃。

### 石崎/日和劝诱与清隆单人隔离

石崎搭话 → Albert/日和夹住清隆并带往Albert房间（SS066直接互证） → 石崎邀请清隆加入偏龙园班强组 → 日和指出岛上合组、条件与主力配置漏洞 → 石崎提出未来凑20m转班并承认龙园不知情 → 本次只传达邀请意愿 → 清隆因自身牵涉月城/White Room而选择单人隔离。

### 池、筱原、小宫与松下

池邀请筱原组队失败 → 栉田把池带走，筱原受伤落单，小宫接近 → 筱原称准备当天确认与小宫组队 → 池嫉妒，平田求清隆追踪 → 小宫自述准备在无人岛告白 → 清隆向铃音回报 → OAA首度确认筱原/小宫/木下三人组正式成立。

### 清隆—惠的救济准备

惠询问清隆组队计划 → 清隆准备单独起步 → 惠只有约`240,000pr`并持“搭顺风车”，安全不足 → 清隆把她的存活列为第一优先，并考虑出售“试炼”筹钱。

### 坂柳—一之濑A/C合作

坂柳用临时邀约和班级下坠压测一之濑 → 提出现二年A/C合作并利用一之濑班的信任力 → 一之濑识破坂柳防止B/C/D三班联盟的目的 → 坂柳先给三人合计`3,000,000pr`救济保证 → 一之濑争取到五人合计`5,000,000pr`并接受，方案纳入“增员”。

### 一年级会议、悬赏与证言层

八神召集一年级代表，主张四班统一/最强四人组 → 高桥把方案理解成最坏时舍弃其余人，八神仍强调完全统一 → 宝泉以岛上大组两个剩余名额都给一年D为合作条件 → 宝泉邀天泽/七濑成组 → 天泽索取让清隆退学的20m全额 → 宝泉表面答应，事后直说不会守口约。

之后，八神经栉田接触清隆 → 声称南云召集六名代表、宣布20m退学任务并由月城在场见证 → 清隆形成南云/月城牵涉认识。八神名单为高桥修、石上京、八神拓也、宇都宫陆、宝泉和臣、七濑翼；天泽不在其中。

- “舍弃其余组”是高桥的最坏解读，不是八神既定方针。
- 六名代表、南云召集/随机目标/展示20m、月城见证，全是八神证言或转述，未独立核验。
- 她目前因连败遵守与清隆/铃音的停战。

### 椿/宇都宫与波田野

清隆故意给尾随者接触窗口 → 椿先出现，宇都宫随后到场 → 宇都宫怀疑宝泉牵涉波田野退学并请求清隆协助逼退 → 椿说“我们也曾盯20m”，承认此前以配对名义接近后已停手。

### 神崎与一之濑改革压力

神崎求清隆借一之濑对他的信任传达“现在这样不行” → 清隆拒绝，直说想看一之濑会怎么做 → 主张班级只能自己解决 → 神崎承认依赖并称已有答案。

### 龙园—葛城转班与卡片交易

龙园用弥彦、坂柳与旧派系冲突刺激葛城 → 假提龙园/葛城/清隆三班强组并公开自己曾败给清隆 → 测试出葛城仍有反抗/复起意志 → 提议葛城转入二年B → 以`5,000,000pr`与坂柳解除旧A/C无人岛契约（现时双方为A/B），结合葛城约`1,800,000pr`与龙园班筹资凑足转班所需20m → 葛城接受并签约，正文叙述其转入二年B、成为转班先例 → 龙园再以约`500,000pr`买“试炼”，并谈妥葛城的“减半”与惠的“搭顺风车”交换。

### 伊吹、铃音与高圆寺赛前契约

石崎报告仅伊吹未组队 → 清隆以病史/600万风险说服铃音见面 → 伊吹因厌恶铃音拒绝 → 铃音用“单人获胜才稍微认可”刺激 → 两人仍未成组。出发日后，高圆寺以本次成绩换毕业前完全自由 → 铃音把门槛定为单人全校第一 → 若未第一，高圆寺只承诺在下一场特别考试协助班级。

### 月城末场

月城要求七濑结束分析 → 声称已提供最大支援、为预算和严苛规则强推校方，并预期自己将被免职 → 宣布最后行动 → 七濑称不再犹豫并被点名。
