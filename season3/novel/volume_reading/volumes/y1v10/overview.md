## 班级投票规则总表

| 项目 | 正文规则 |
| --- | --- |
| 同班投票 | 每名学生必须给三名不同本班学生投赞美票、给另三名不同本班学生投批评票。 |
| 外班投票 | 每名学生另须给一名其他班学生投一张赞美票；没有外班批评票。 |
| 禁止项 | 不得自投、不得对同一对象重复、不得空白或弃权；缺席/生病者也必须完成投票。 |
| 计分 | 赞美与批评相抵，以最终净结果排序。公开的是每人最终结果；个人投给谁永久匿名。 |
| 保护点 | 净赞美评价第一获得一个不可转让的保护点；每点可抵销一次未来退学处分。 |
| 退学 | 净批评评价最后一名退学。全员净零则重投；同分先重投，仍同分则由校方用未公开特别方法处理。 |
| 救助 | 唯一规则内救助为`20,000,000pr`取消退学。本考试不存在`300cl`救助。 |
| 班点 | 本次退学不另扣班级点数，考试本身也不产生班点增减。 |

#### 投票动作

1. 每人向本班三名不同学生投赞美、向本班另三名不同学生投批评。
2. 每人另向其他班一名学生投一张赞美。
3. 不得自投、不得重复、不得空白/弃权；缺席或生病也必须完成。
4. 个人投向永久匿名，所有学生最终评价结果在考试后公开。

#### 结算

1. 赞美与批评相抵，以净结果排序。
2. 净赞美评价第一获得一枚不可转让保护点；每点抵一次未来退学。
3. 净批评最后者退学。
4. 全员净零则重投；同分先重投，仍同分由校方未公开特别方法解决。
5. 本考试不另扣班级点数。
6. 唯一取消退学手段为`20,000,000pr`，没有`300cl`档。

#### 山内链

坂柳用恋爱/赞美承诺诱导山内 → 山内经栉田拉票攻击清隆 → 坂柳刻意让惠被拉入、预期泄漏 → 惠自主报告 → 栉田另向清隆供出主链 → 清隆请学向铃音提问 → 学给铃音成长方向 → 铃音公开指名山内 → 清隆若铃音失败则准备亲自推进。

- 坂柳的泄漏设计不能抹去惠自主报告。
- 清隆的间接促发不能抹去学、铃音的独立判断。
- 山内低价值、坂柳的私人报复、以及坂柳对清隆的强敌欲/想看清隆认真三因并存。
