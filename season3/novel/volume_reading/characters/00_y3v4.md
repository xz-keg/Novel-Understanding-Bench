| [池宽治](ike/y3v4.md) | 他会为筱原出头、尝试与清隆和解，却仍受栉田吸引，也没能阻止筱原逼她下跪。筱原提前分给他的代币让他最后高于女友；得知她退学后，他失控大闹。 |
| [伊吹澪](ibuki/y3v4.md) | 她在学力课题中连续落后，又被葛城少分代币，真的以为自己将被放弃。她仍出面制止栉田受辱，终点前打中清隆一拳，最后靠栉田转币免于退学。 |
| [葛城康平](katsuragi/y3v4.md) | 他反对从一开始牺牲自己班的同伴，却接受了让伊吹误以为被抛弃、借她掩护淘汰A班学生的安排。保护伊吹的底线和实际施加给她的痛苦，在本卷同时存在。 |
| [龙园翔](ryuuen/y3v4.md) | 他看见清隆望向日和，将她置于真实退学风险中，赌清隆会为她放弃奖励。清隆最后确实去救人，金田却为此直接反抗他； |
| [椎名日和](hiyori/y3v4.md) | 她理解龙园拿自己作诱饵的意图，也主动拒绝用个人点数保底。清隆赶到后，两人互相告白并牵手； |
| [一之濑帆波](ichinose/y3v4.md) | 她与堀北合作；结尾看见清隆牵着日和下船，并在独白中说无法压制自己的感情。 |
| [七濑翼](nanase/y3v4.md) | 她试图争取天泽一起阻止清隆毕业后回到笃臣身边，也承认排除石上的尝试失败、让别的同班学生付出退学代价。她提供的保护与父亲情报尚未核实，天泽只答应考虑。 |
| [天泽一夏](amasawa/y3v4.md) | 她起初不愿帮助七濑改变清隆的选择，仍把白屋视为归处；听到父亲可能出售自己的情报后，她开始认真考虑另一条路，但尚未答应合作。 |
| [石上京](ishigami/y3v4.md) | 他没有在本卷正面出场。七濑报告自己针对他的行动失败，并拿出资料把他与笃臣的监视安排联系起来； |
| [绫小路笃臣](ayanokouji_father/y3v4.md) | 他本人未出场，七濑却把阻止清隆回到他身边作为自己的目标，并以石上资料说明他仍可能通过他人监视儿子。 |
| [天泽社长／天泽一夏的父亲](amasawa_father/y3v4.md) | 本卷只由七濑展示有关他的资料：公司被指经营不当、资金困难，并可能准备将一夏交给海外买家。天泽受到冲击，但无法核实。 |
| [月城理事长代理](tsukishiro/y3v4.md) | 他本人没有出现。七濑转述了他对天泽、八神旧任务及清隆回归意愿的说法。 |
| [白屋](white_room/y3v4.md) | 本卷的新信息来自七濑与天泽的私下谈话：石上的监视、清隆毕业后的选择，以及天泽可能面对的家庭威胁。相关资料没有向普通学生公开。 |
| [真田康生](sanada/y3v4.md) | 他既愿意协助清隆，也会当面反对对方羞辱同学。终盘他趁伊吹打人时向栉田解释并转币，之后又同意为清隆去救日和提供援助。 |
| [吉田健太](yoshida/y3v4.md) | 他会质疑清隆的刻薄行为，也愿意在理解安排后合作。终盘清隆用白石作类比说服他，他不仅点头，还主动找真田、森下凑出援币。 |
| [森下蓝](morishita/y3v4.md) | 她仍会作弄人，也能当面指出清隆的做法令人不安。她拒绝无理由给栉田自己的币，终盘却在吉田请求后借币给清隆。 |
| [王美雨](wang_meiyu/y3v4.md) | 她受过栉田伤害，却不愿因此看着对方被欺负，主动找清隆求助。终点前她又反对让同班人垫底，高圆寺随后给她三十枚保险代币，陪她过线。 |
| [高圆寺六助](koenji/y3v4.md) | 他独自赶到终点附近观察，判断王美雨受到的危险不大，仍主动现身、给她三十枚代币，陪她过线。他把这说成报恩，没有因此承诺听从堀北或长期保护所有同学。 |
| [西川亮子](nishikawa/y3v4.md) | 她最担心的是白石，连续两次要求清隆确认并照顾对方。她不愿牺牲自己换白石留下，却接受牺牲别人来保住两人，对清隆的信任仍有条件。 |
| [白石飞鸟](shiraishi/y3v4.md) | 她主动说自己累了，但认为前场第二名值得，并展示初始十二枚代币。西川随后因担心她而两次求助，吉田也因清隆拿她作类比，答应帮助日和救援。 |
| [长谷部波瑠加](hasebe/y3v4.md) | 她承认曾给清隆建议，虽有罪恶感仍不后悔；这次又主动恢复“隆儿”的称呼，提出暑假先两人见面，得到答应。关系在缓和，旧小组没有因此复原。 |
| [桥本正义](hashimoto/y3v4.md) | 他提醒同学谨慎公开代币，也在考后追问清隆救日和的决定。帆波从他和吉田那里得知救援，随后亲自去看船； |
| [平田洋介](hirata/y3v4.md) | 他提出跨班保护同组学生，并实际给两人少量代币；日和遭当诱饵时，他反对这种方式、阻止金田动武，却又想看清隆会怎样选择。这份好奇与保护原则之间存在张力。 |
| [金田悟](kaneda/y3v4.md) | 日和被押上赌局后，他第一次如此强烈地反抗龙园，抓住衣襟、要求撤回命令，还提出用自己的保护点救她。办法没有奏效。 |
| [堀北班／三年A班](class_d/y3v4.md) | 代币考试为A班带来二百班级点奖励，却也让筱原退学、池失控。点数上的胜利没有解决班内旧伤、分配权被滥用和对领袖的信任问题。 |
| [网仓麻子](amikura/y3v4.md) | 她无争议地成为第3组D班代表，按四人均分代币，也愿承担合作课题里收益较少的位置。她有具体比赛成绩，不只是栉田与帆波之间假想的传话人。 |
| [轻井泽惠](kei/y3v4.md) | 她没有本卷新的正面行动。清隆凝望日和时在心里想到她，帆波在结尾也回顾自己曾把她当作必须跨过的阻碍，这些都不是惠本人的新态度。 |
| [鬼头隼](kito/y3v4.md) | 他作为第6组C班成员与清隆一行相遇。 |
| [町田浩二](machida/y3v4.md) | 他在两个小组偶遇时主动提出共享代币情况，希望获得安心。清隆没有提供余额，只给出保护全班的口头保证。 |
| [真岛智也](majima/y3v4.md) | 他在生存游戏结束后继续宣布代币考试，说明班号、分组、奖励和退学规则。学生随后怎样利用规则。 |
| [南方小梢](minamikata_kozue/y3v4.md) | 她在投票讨论中先提出全员一致的稳妥方案，也实际赢下牌战，并与网仓坚持到平衡课题最后。 |
| [森山进](moriyama_susumu/y3v4.md) | 他会在跨班讨论失去方向时主动劝冷静、找妥协，并催大家回到合作。牌战的对手是真田，结果也已给出：真田获胜。 |
| [诸藤梨花](morofuji/y3v4.md) | 她在牌战赢了伊吹，却在双人平衡时受清隆点名注视影响而落地，使两人一组止于第三。成绩和恐惧要按具体场合记录。 |
| [坂上数马](sakagami/y3v4.md) | 他作为第8组监视员听到清隆针对伊吹的安排，承认自己心情复杂，又确认表面行为不违规。他建议堀北可告诉龙园，没有亲自泄露或改规则救人。 |
| [佐藤麻耶](sato/y3v4.md) | 她没有新一轮的独立行动，但前场被优先攻击的经过继续影响堀北对内线的怀疑。 |
| [里中聪](satonaka_satoshi/y3v4.md) | 他作为第6组C班成员靠近清隆一行交流，听见领袖保证不让同班退学，没有独立公开余额或转币。 |
| [园田正志](sonoda/y3v4.md) | 他是第3组B班的园田正志，会追问规则、争取本班收益，也会在听不懂安全线时直接发问。与堀北班女生园田千代不是同一个人。 |
| [须藤健](sudo/y3v4.md) | 他的前场观察促使堀北怀疑情报泄露；筱原退学后，他又和同学一起制止失控的池。两处作用都有具体依据，尚未展示长期安抚的结果。 |
| [墨田诚](sumida_makoto/y3v4.md) | 牌战输给吉田，其他个人成绩未单独展示。 |
| [漆原／第3组监视员](urushihara_monitor/y3v4.md) | 他向第3组解释并执行课题流程，监督投票、分配和终点规则。学生如何隐藏动机、选择退学目标，并没有成为他已知或认可的事。 |
| [山村美纪](yamamura/y3v4.md) | 她在第6组参加新考试，随后与町田、里中一起接近清隆交流。前场坚持带来的疲惫被清隆认可，关于白石的调查仍没有新答复。 |
