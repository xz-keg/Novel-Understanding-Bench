| [鬼龙院枫花](kiryuin/y2v4.md) | 被难以看透的清隆吸引，亲自接近和试探；看到两个成人围攻时又走了出来，明知打不过也愿意帮他争取时间。 |
| [坂柳有栖](sakayanagi/y2v4.md) | 接下清隆的求助，自己组织拦截、侦查与救援；既享受交锋，也把帮助变成未来认真对决的约定。 |
| [龙园翔](ryuuen/y2v4.md) | 接下坂柳的委托拦住宝泉，挨打后借同伴反击；赢了这场架，却也付出重伤退出考试的代价。 |
| [宝泉和臣](hosen/y2v4.md) | 会留证、探情报，也会利用七濑泄密来争取单挑；最后却被龙园与同伴夹击，重伤退出考试。 |
| [南云雅](nagumo/y2v4.md) | 凭三年级的人手与合作争取胜利，却在关键时刻把注意力留给清隆，关掉对讲机后被击昏，最终以两分之差屈居第二。 |
| [高圆寺六助](koenji/y2v4.md) | 在长时间围堵中继续独自得分，最后拿下全校第一，完成与铃音交换自由的条件。 |
| [椿樱子](tsubaki/y2v4.md) | 愿意用退学作代价组织袭击，也认真替宇都宫留下退路；计划失败后，她才更清楚地面对彼此无法完全信任的处境。 |
| [宇都宫陆](utomiya/y2v4.md) | 想保护同学，也愿意接受伤害别人的办法；他对椿有自己的顾虑，背着她另与一个未具名的人联络。 |
| [八神拓也](yagami/y2v4.md) | 带着平板和办法来参与围捕，却发现椿早有准备；面对质疑仍保持圆滑，真正的私下行动没有在本卷说清。 |
| [桐山生叶](kiriyama/y2v4.md) | 为压住高圆寺亲自带队，懂得避开明显违规，却逐渐让出现场主导；追击和封锁都失败后，只能先放人离开。 |
| [三木谷](mikitani/y2v4.md) | 想靠拦下高圆寺换取A班毕业的机会，越急越愿意用威胁和暴力；最后却在倒数名单中被宣布退学。 |
| [石崎大地](ishizaki/y2v4.md) | 看见清隆就想拉他一起玩，也仍愿意跟龙园参加危险的伏击；亲近朋友与参与暴力，都是本卷真实的一面。 |
| [山田阿尔伯特](albert/y2v4.md) | 不喜欢无谓的打架，却信任龙园能把班级带好，因此仍配合伏击，牢牢压住宝泉。 |
| [白波千寻](shiranami/y2v4.md) | 夜里与同伴走散，害怕得快哭出来，却仍惦记朋友、守住不便透露的组内消息。 |
| [小桥梦](kobashi/y2v4.md) | 白波走失后与竹本一起寻找，会合时立刻喊出朋友的昵称。 |

| [西野武子](nishino/y2v4.md) | 与新旧队友都能自然相处，看见石崎说过头、闯得太急，就直接把他拦下来。 |
| [津边仁美](tsube_hitomi/y2v4.md) | 是六人组里唯一来自一之濑班的人，却已能自在地加入玩笑，替同伴打圆场。 |
| [矶山渚沙](isoyama_nagisa/y2v4.md) | 与日和、诸藤组成的小组，已同石崎三人合并，继续参加考试。 |
