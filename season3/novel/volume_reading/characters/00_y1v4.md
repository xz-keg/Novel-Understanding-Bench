| [轻井泽惠](kei/y1v4.md) | 她害怕重新受欺凌，也会为维持地位伤人；遭到绫小路安排的袭击和胁迫后，开始在保护承诺下协助他。 |
| [平田洋介](hirata/y1v4.md) | 他愿意保护同学、拒绝报复，也因急于找到解决办法而泄露私事、交出信任；杉村的往事解释了他的后悔。 |
| [堀北铃音](horikita/y1v4.md) | 她分析规则、应付龙园、配合绫小路掩饰实力，却不知道他的地下层安排，并误判了栉田身份是否守住。 |
| [一之濑帆波](ichinose/y1v4.md) | 她争取合作，也保留班级利益；与滨口准备公开手机，看穿两层换机后，选择让别班误答获利。 |
| [龙园翔](ryuuen/y1v4.md) | 他追查无人岛幕后者、集中班内消息并试探合作，最后使C班取得最大收益；部分获知答案的过程仍未揭晓。 |
| [栉田桔梗](kushida/y1v4.md) | 她继续主动接近同学，夜晚又因自称寂寞抱住绫小路；龙组优待者身份确定，最初泄露的途径尚未展示。 |
| [D班](class_d/y1v4.md) | 分组暴露了合作不足，终局又出现新的联络与协作。D班净增50班级点、取得300万个人点，仍被C班的收益压过。 |
| [幸村辉彦](yukimura/y1v4.md) | 他积极组织却常轻视同伴；围堵时仍不顾阻拦先救人，终局则因不知道第二层换机而真切地以为失败。 |
| [滨口哲也](hamaguchi/y1v4.md) | 他主动反驳A班、先提出公开邮件，也与一之濑试过更换SIM；有自己的表达和实际准备。 |
| [神崎隆二](kanzaki/y1v4.md) | 他当面阻止葛城擅自代替别班表态，参与龙组讨论并交换消息；没有完整展示由他主导的终局安排。 |
| [葛城康平](katsuragi/y1v4.md) | 他为保持A班领先坚持不讨论，能清楚说明理由，却没防住别人从讨论之外获取答案。 |
| [伊吹澪](ibuki/y1v4.md) | 她仍想与堀北分胜负，却不参加真锅等人的围攻；终局主动展示手机，并向同伴追问。 |
| [高圆寺六助](koenji/y1v4.md) | 他无视船员提醒、拒绝室友讨论，却在第一天准确答出猴组优待者，按自己的节奏赢得自由时间。 |
| [佐仓爱里](sakura/y1v4.md) | 她主动商量室友与考试的烦恼，也练习邀约；邮箱没有被交给山内，她却仍不知道自己的名字怎样被利用。 |
| [山内春树](yamauchi/y1v4.md) | 他用身体威吓追讨邮箱，又被送相机的说法带动投入考试；鸡组答案没能寄出，内容与正误都未知。 |
| [外村秀雄](sotomura/y1v4.md) | 他会提醒保密，也会侮辱惠、为了动画拒谈；打牌时好胜易怒，终局没有参与换机内情。 |
| [须藤健](sudo/y1v4.md) | 他自称尽力应考但被抢先寄答，仍想靠近堀北；面对龙园激动，却在她制止后坐回去。 |
| [町田浩二](machida/y1v4.md) | 他坚持葛城方针、替惠阻止偷拍，终局认真检查手机仍被误导；实际发送错误答案的人没有公布。 |
| [森重卓郎](morishige/y1v4.md) | 他与A班同伴保持沉默；派系信息来自转述，一之濑怀疑他会抢答，但没有直接确认。 |
| [真锅志保](manabe/y1v4.md) | 她从替朋友追究碰撞走向带头围堵和施暴，又逼梨花参与；受到操纵不消除她实际作出的选择。 |
| [诸藤梨花](morofuji/y1v4.md) | 她确认曾被惠撞到，起初拒绝参与殴打，后来在真锅带动下主动加重暴力。 |
| [薮菜菜美](yabu/y1v4.md) | 她参与尾随、围堵并在地下层到场，持续支持真锅一方；个人台词和动作没有全部拆开描写。 |
| [山下沙希](yamashita/y1v4.md) | 她参与围堵并明确说已不能原谅惠，推动冲突升级；地下层到场，未单独描写具体殴打动作。 |
| [茶柱佐枝](chabashira/y1v4.md) | 她质疑星之宫的分组动机，也回答点数修改校规的咨询；先前对绫小路的威胁仍影响两人关系。 |
| [星之宫知惠](hoshinomiya/y1v4.md) | 她以仍有课题为由安排一之濑进入兔组，受到同僚质疑；又提供SIM解锁信息，未见给学生下达调查命令。 |
| [真嶋智也](majima/y1v4.md) | 他严厉说明规则，也耐心解释疑问，并对同僚提出职业伦理警告；最终成绩由学校邮件公布。 |
