| [桥本正义](hashimoto/y2v10.md) | 他不愿把毕业希望交给坂柳，选择亲手制造败北来迫使她挖清隆。行动确实改变了考试，也让神室离开，并把自己推到与班级领袖决裂的位置。 |
| [坂柳有栖](sakayanagi/y2v10.md) | 她能看懂许多规则和对手，却没有因此避开背叛，也低估了失去神室对自己的影响。告别以后，她才愿意说出朋友这个词。 |
| [神室真澄](kamuro/y2v10.md) | 她会嫌麻烦、反驳坂柳，也在关键时刻主动保住山村的选择机会。抽中退学签后，她仍照顾了追赶自己的坂柳，最后留下一个要求。 |
| [王美雨](wang_meiyu/y2v10.md) | 她一直记得匿名的帮助，害怕知道答案，却还是决定去道谢。追查、选择礼物和再次开口，都有她自己的坚持。 |
| [高圆寺六助](koenji/y2v10.md) | 他承认自己会报答真诚的帮助，却仍拒绝为班级的期待行动。考试里，他利用自由交白卷，也能在需要时自己答对。 |
| [龙园翔](ryuuen/y2v10.md) | 他把比赛的关键放在取得对手名单和控制名次，最终从垫底翻到第一。胜利是真的，班级原有的学力不足也没有随之消失。 |
| [山村美纪](yamamura/y2v10.md) | 她被淘汰后进入退学抽签，恐惧得无法伸手。神室没有接受让她直接离开的结果，拉她一起抽，最后留下的是她。 |
| [渡边纪仁](watanabe/y2v10.md) | 他因为想找朋友聊喜欢的人而折返，却撞见了难以处理的场面。紧张过后，他主动说出自己的秘密，既想取得信任，也想得到恋爱上的帮助。 |
| [神崎隆二](kanzaki/y2v10.md) | 他仍担心一之濑为了保护所有人而放弃争胜，愿意当面反对；对清隆的信任增加，也已经被一之濑看出来。 |
| [轻井泽惠](kei/y2v10.md) | 和好后的亲密没有消除她对退学的恐惧。她会直接请求保护、抗议冒犯，也在连续被指名时承受了旁人不能替她轻描淡写的压力。 |
| [佐藤麻耶](sato/y2v10.md) | 她会拿朋友的亲密开玩笑，也会在惠害怕时站到前面。保护朋友是她已经做出的行动，不只是未来承诺。 |
| [椎名日和](hiyori/y2v10.md) | 她为班级获胜却难以高兴，因为看见了赢法留下的问题。她愿意向清隆说出这种不安，也会因与他相处开心而提醒自己别忘了分寸。 |
| [森下蓝](morishita/y2v10.md) | 对惠的冒犯、考试里的警告和制作抽签，都是具体做过的事，不必用一个怪人标签概括。 |
| [栉田桔梗](kushida/y2v10.md) | 她仍会故意挖苦别人，也确实在考试里给出了有用的帮助。能合作与让人受伤的习惯同时存在。 |
| [伊吹澪](ibuki/y2v10.md) | 她为不服输真的做了便当，挨批后仍嘴硬，也还是答应继续去堀北那里吃饭。 |
| [池宽治](ike/y2v10.md) | 他兴奋地提出一个自己反复算过的方案，接受否决时会失落，也能从解释和鼓励中继续参与讨论。 |
| [平田洋介](hirata/y2v10.md) | 他努力让同学在恐惧中还能讨论，支持堀北也容许质疑。对高圆寺，他能开口请求，却不能让对方一定听从。 |
| [须藤健](sudo/y2v10.md) | 他继续努力，也开始感到兼顾学习与篮球的压力。对高圆寺不合作会生气，真看到对方可能出局，又不希望同学失败。 |
| [鬼头隼](kito/y2v10.md) | 他继续维护坂柳、照顾身边事务，也会自己判断该攻击谁。强硬反应没有让他自动掌握全部布局。 |
| [前园](maezono/y2v10.md) | 她把寒假里的疑虑带到全班，要求重新考虑司令人选；另一方面，她与桥本交往、提供录音的事实也开始被读者知道。两件事不能不加区分地合成同一条命令。 |
| [茶柱佐枝](chabashira/y2v10.md) | 她传达面谈与考试安排，确认本班到齐后改到A班监考。她在场执行程序，不能被写成选出神室的人，也不能说她完全没见抽签。 |
| [星之宫知惠](hoshinomiya/y2v10.md) | 她在龙园班监考，既想自己的班获利，也一再猜错眼前的沉默。她看到了完美防守，却没看出机关。 |
| [堀北班（原D班）](class_d/y2v10.md) | 班级以B班身份参加生存与淘汰，最终第三、扣五十班级点数而无人退学。结果来自指挥、同学作答、情报帮助与外班合作，不能归给单一人物。 |

## 其他人物的本卷补充

- [秋山（健身房职员）](akiyama_gym_staff/index.md)：清隆陪小美找高圆寺时，她在健身房向他打招呼；他这次仍没执行真岛的托问。考后短篇里，她请一之濑回柜台补有缺漏的文件，客观上留下清隆与网仓独处，但没有她有意促成谈话的证据。
- [网仓麻子](amikura/index.md)：她与一之濑参加考前聚会，反问临考试才谈四班求和是否太晚；散场后没看见一之濑折返的拥抱，也没在场接受渡边追求。
- [本堂辽太郎](bondo/index.md)：他参加池的六十八分提案会，先疑惑为什么主动变成负三十二分，听懂后又指出三十二人同时装病很不自然。堀北解释手机合作的反制，再鼓励大家提意见。考试第十轮他实际被淘汰，留在教室，最终班级第三而没有退学。
- [葛城康平](katsuragi/index.md)：龙园迟迟不报首轮目标时，他闭目等待，没有在本卷说清自己知道多少布局。下半场第十一轮他与日和、时任、野村、伊吹全部被守中，自动得分。胜利后，他严肃地与同伴走向商场。
- [石崎大地](ishizaki/index.md)：他在上半场两错时仍打瞌睡，第七轮成为首个淘汰者，最后因班级翻盘而留下，考后兴奋得手舞足蹈。
- [松下千秋](matsushita/index.md)：第十二轮，一之濑用新闻题攻击，她和清隆、惠一起作答。清隆不知道喝珍茶的含义，她与惠都答对，给本班得分。这是本卷明确的答题表现。
- [二宫唯](ninomiya/index.md)：第一轮英语题，她被堀北指名，一之濑成功守住她与渡边，两人自动获得分数。本场并未展示她自己解题。考试时她所属的是一之濑C班。
- [野村雄二](nomura/index.md)：下半场第十一轮，坂柳体育难度三指名，他与葛城、日和、时任、伊吹全部被龙园守住，自动得分。没有独立发言或他已知传讯机关的证据。
- [小野寺](onodera/index.md)：第二轮美食题，她与长谷部、平田答对，高圆寺和幸村答错；后来第十八轮又与惠、长谷部被守中。前者是实际作答，后者是自动得分，不能都只写成没有表现的名单。现有译文此处写萱乃，与此前译名不一，卡片继续用姓氏。
- [外村秀雄](sotomura/index.md)：他在第四轮被坂柳以难度二的美食题攻击，只有高圆寺答对，他与三宅答错；第八轮，他与伊集院同时淘汰。最终本班第三，没有退学。被指名回答是防守，不是记录所说参加进攻。
- [杉尾](sugio/index.md)：他在A班落到最后时已是五名淘汰者之一，随后参加抽签，在町田之后、鸟羽之前抽到白签，获得留校结果。原文没有列出他此前三道错题，也没有本人长篇发言。
- [真岛老师](majima/index.md)：他在一之濑班监考，下半场开始前提醒还有一分钟，请大家就座准备。这时一之濑查看与龙园的记录，但老师并未因此取得她的全部内心或参与交易。清隆去健身房时还想到他的秋山委托，却本次没问。
- [坂上老师](sakagami/index.md)：茶柱确认B班全到后离开，他接任监考，公布实际攻防顺序、休息和作弊处理要求，按堀北口述登记攻击与守护，推进作答。
- [幸村辉彦（启诚）](yukimura/index.md)：谈升学就业时，他建议把A班特权用于进入大企业，强调稳定，是个人想法，不是学校保证。考试第二轮，他没及时想起美食题答案，答错后懊恼并向堀北道歉；是堀北主动提出下一轮守他，他接受。对手改选别人，守护没命中，不是他自己请求特殊待遇。
- [筱原皋月](shinohara/index.md)：她起初惊讶池有制胜方案，随后与他亲密同行参加讨论，也说明自己事前已经听过，觉得是好主意。堀北解释后方案未被采用，她没有提供独立反制。考试第四轮与须藤、第十一轮与小美一起被守中。
- [宫本](miyamoto/index.md)：他参加池的提案会，比本堂先明白五人全守的算术，又怀疑装病能否成立。考试第三轮美食答对，第十一轮又答对棒球规则，和同伴击掌，说玩游戏学到的知识已经多次帮上忙。
- [金田悟](kaneda/index.md)：上半场龙园迟迟不报目标，他没有代替下令。星之宫问为何不查手机，他说平时有学习，不想临时勉强灌知识、打乱习惯，微笑回应。
- [时任裕也](tokito/index.md)：下半场龙园要求同学别答错时，他当面反对，要求作为司令应多想办法守护。龙园拿他已有两错、可能优先退学威胁，随后却把他列入第十一轮五个守护者，全员守中。他看到结果惊讶，不是事先知道机关后配合演戏。
- [真田康生](sanada/index.md)：上半场他属于龙园反复攻击的约八名对象之一，具体个人答题没有逐条列出。下半场森下说泄密，他接着建议先让全员停用手机确认，坂柳拒绝。他在班级危机里会主动提办法，未因此查出桥本或藏机地点。
