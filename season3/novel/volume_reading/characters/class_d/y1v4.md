# D班｜一年级第四卷

这场考试把D班拆进不同小组，班级缺少合作的问题便更加明显。幸村想认真讨论，却让同组的人觉得被轻视；惠失去熟悉的关系后很难维持强势；堀北与平田忙于龙组，也不能掌握每个人的行动。高圆寺自己提前答题，山内被奖励和追求佐仓的念头带动，许多人都在各自寻找出口。

绫小路开始把这些分散的关系连起来。他向平田获取消息，以轻井泽的真实优待者身份设计换机，再让幸村扮演假答案。兔组因此获胜，过程却包含对惠的伤害和对幸村的隐瞒。共同获益并没有使所有参与者都知道自己在配合什么。

堀北虽然不喜欢绫小路擅自增加成员，也留下来讨论。

## 考试规则与结果

全年级按干支分十二组，各组混合四班学生、设一名优待者。三个实际考试日之间夹一天休息，每天13时和20时各讨论一小时。最后一天21时结束讨论，21:00—21:30仍可提前抢答，21:30—22时才是全员正常作答窗口，23时公布结果。

| 情况 | 个人点数 | 班级点数 |
| --- | --- | --- |
| 正常窗口中，除优待者及其同班者外全员答对 | 全组各50万，优待者100万 | 不变 |
| 正常窗口未能全员答对 | 只有优待者50万 | 不变 |
| 提前答对 | 答题者50万 | 答题班+50，优待者班−50 |
| 提前答错 | 真优待者50万 | 答题班−50，优待者班+50 |

每人只能答一次、只能答本组并须使用自己的手机；优待者无权作答，同班者提前答对或答错都不受理。一次有效提前作答就结束该组。校方不公开答题者及优待者姓名，可用临时汇款ID或分期发放保护匿名。

偷手机、恐吓取得身份、擅用他人手机作答、谎报受威胁，以及修改、复制、转寄校方邮件都受禁止。讨论期间离场需申请，最终散场后还有禁止与别班交谈的时段。换手机利用了持机人与邮件收件人不同；SIM解锁可以付点办理，但本卷没有给出费用。

| 班级 | 本次班级点变化 | 本次个人点总收入 |
| --- | ---: | ---: |
| A | −200 | 200万 |
| B | 0 | 250万 |
| C | +150 | 550万 |
| D | +50 | 300万 |

D班的结果可以分开看：兔组别人误答，惠得到50万、班级+50；马组南被答中，班级−50；高圆寺答对猴组，个人50万、班级+50；龙组全员答对，栉田100万、堀北和平田各50万。这份分解根据身份、规则与结果合起来得出，学校只公布了各组类型和四班总数。

所以D班确实获利，却被C班更大的进账压过。堀北原以为守住栉田就能赢，结果龙园早已知道姓名，还让龙组全员得奖。他的真正信息来源和说服过程，此时仍没说清。

另附的SS018解释了选人办法：按组内姓氏的五十音顺序排序，取干支序号对应位置；兔第四名是惠，龙第五名是栉田。老师在说明会上只说“严正调整”，没有把这份算法交给学生。
