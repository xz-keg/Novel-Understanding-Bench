# D班｜一年级第三卷

这次无人岛考试让D班第一次用读书以外的本领争取分数，也暴露出“想一起赢”和“愿意一起生活”之间的距离。厕所、水、睡觉的地方，每一件都涉及真实的不便，不是喊几句团结就能决定。

开始时，池与幸村尽量省点，筱原坚持基本条件，惠反而表示能忍。平田经过争论才决定买厕所，又给出最多使用约180点、尽量保留120点的预算。池的露营经验、须藤的捕鱼、佐仓发现的玉米及其他同学采集的食物，才让这个安排逐渐有了实际成果。预算不是已结算的成绩，阶段性“约花一百”也不是精确流水。

班级的合作一度变好。池与筱原互相道歉，饮水开始让同学自愿选择，大家愿意按本领分工。伊吹受伤后被收留，平田不愿丢下她；其他同学还考虑到C班缺席点名会失分的好处。

失窃事件又使男女分裂。赃物在池包里，随后被塞到绫小路手中，平田检查发现却没有公开；女生认定男生有问题，开始划分营地。佐仓替绫小路说话又被取笑。火灾与暴雨接着到来，平田一度无法指挥，同学之间仍在互相怀疑。这些问题直到考试结束也没有全部解决。

考试的关键规则如下；点数先在本次考试中使用和扣除，结束后才把剩余与奖励加到班级点数。

| 事项 | 本卷规定 |
| --- | --- |
| 起始与期限 | 每班300考试点，一周，8月7日中午结束；A班因一人缺席从270点开始 |
| 基本生活 | 学校配给两顶八人帐篷、两支手电筒、一盒火柴等；其余可用考试点购买 |
| 退场与点名 | 体况或重伤退场扣30；每天8时、20时点名，缺席每人扣5；退出不能重新参加 |
| 环境与伤害 | 污染环境扣20；对别班暴力、掠夺、破坏器具，规定会使所属班失格并没收当事人个人点 |
| 占领据点 | 只有领导者可用刻名卡；每次占领有效8小时、得1点期末才结算的奖励；未经许可使用别班据点扣50 |
| 猜领导者 | 每猜对一班得50，被猜班扣50；猜错扣50；本班领导者被猜中，还会失去已积累的据点奖励 |
| 更换与下限 | 无正当理由不能更换领导者；本次考试点最低为0，不继续扣成负数 |

堀北的卡被伊吹偷走并让龙园、葛城验看，泄露的是真实姓名。绫小路却在她病倒后将她送医、交回堀北领袖卡，随后接任领导者，旧情报因此不再有效。19:58办理病退，使堀北只扣退场30点，没有另扣当晚点名5点；绫小路自己没赶回点名，扣了5点。高圆寺此前退场也扣过30点。

最后正式结果是D班225第一、B班140第二、A班120第三、C班0第四。平田公布前说剩125点，结合猜对A、C两班的100点，可解释D班结果；学校只公布了总成绩，没有逐笔公开采购和占领奖励。

A/C联手有伊吹视角的现场描写；金田如何取得B班领导者资料，也没有展示全过程。这些解释与结果有关，但并未逐项得到证实。

火灾、偷卡和森林打斗没有在本卷得到校方审理，指南由谁焚毁、相机怎样损坏也没有直接揭明。学校配发的手表可以监测身体状况、定位和求救，但本卷没有显示它能记录下全部冲突经过。
