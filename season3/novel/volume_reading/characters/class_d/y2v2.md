# 堀北班（二年D班）｜二年级第二卷

同班组队的班点奖励由本班获得；跨班组队的奖励按规则分配。铃音和平田一起听大家讨论，须藤也提出三班联合。铃音随后请同学别急着定组，仍保留个人选择。

大家的考虑各不相同。平田优先照顾本班较需帮助的人；松下觉得清隆可靠，主动邀请；爱里、明人与波琉加准备一起，启诚另有外班邀请。池想与筱原同行，却因嘴硬错失机会，筱原最后与小宫、木下正式组队。到截止日，只有清隆、铃音、高圆寺仍独自参加。

高圆寺在出发前提出交易，铃音将其谈成“单独全校第一换毕业前自由与保护，失败则下一场仍要贡献”。全班旁观到他答应，还没有看见成绩。茶柱检查三十九人都无身体不适，并希望他们全数回来。

本卷的日程是七月十九日出发、二十日开考，八月三日结束并公布名次，四日至十一日为八天七夜的船上假期。八月个人点数等岛考结果后再汇入；本卷没有新的四班总点表和正式名次结算。

- 初始组限同年级，二、三年级最多三人，一年级最多四人。二年级允许单男、两男、三男、单女、两女、三女、一男两女，确认后不能换组。
- 岛上可合并为最多六人的大组，四人以上女生须至少占半。合并还有未公开条件，不能预先保证一定能凑齐。
- 只要还剩一名组员，队伍就能继续；退出者共享最终名次。最后一人也退出，才全组失格。
- 倒数五组面临退学。二年级每组救济费六百万，按人数分摊，各人可以只付自己那份自救，须在登船前持有所需点数，开考后不能借入。
- 前三组分别获三百、二百、一百班点；若跨班，按所含班级数均分并四舍五入。组员个人奖励分别为一百万、五十万、二十五万，第一另有一点保护点。前50%与前70%的五万、一万档位如何叠加，原说明没有明确交代。
- 前三班点对应倒数三组。跨年级时由后组所在年级各班承担；同年级时，倒数第一、第二、第三所含班级各扣一百、六十六、三十三；若后组包含四班，则每班七十五、五十、二十五，不足由学校补。

每人随机得到一张卡，只能同年级跨班交易，第一次转手以后不能再转，相同效果不叠加。三种特殊卡每学年各一张。

| 卡片 | 本卷公布的效果 |
| --- | --- |
| 领先 | 开考时可用点数乘1.5 |
| 追加 | 持卡者个人点数奖励乘2 |
| 减半 | 持卡者的救济支出减半 |
| 搭顺风车 | 得到开考时指定小组个人点数奖励的一半；后来与该组合并则失效 |
| 保险 | 因身体不适退出，可得到一天恢复缓冲；违规不适用 |
| 增员 | 允许第七名成员加入，不受性别比例限制 |
| 无效 | 持卡者救济支出为零 |
| 试炼 | 班点奖励乘1.5，增加部分由学校补；未进前30%则小组受罚 |

这些是学生作选择时面对的条件。清隆卖卡为惠准备救济、铃音与高圆寺谈约定，都是利用已公布规则作出的安排，收益与后果要等真正考试。
