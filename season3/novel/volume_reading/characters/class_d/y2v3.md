# 堀北班（二年D班）｜二年级第三卷

全班分散在岛上，有人以身体能力争分，也有人第一次在不擅长读书以外的题目里获得优势。须藤握力第一，须藤、池、本堂组动画问答第一；爱里、明人、波琉加组却在第四天落到倒数第九。

池为筱原低落，经过夜谈才坦白心意，重新生火、钓鱼。小宫、木下重伤以后，筱原只剩自己应考，池、须藤、本堂支持她，清隆则去找龙园、坂柳商量帮助。各方还在准备，本卷没有正式合并救助或全员安全的结果。

高圆寺在第五天赢拔河和男子游泳，一度第一，第七天又暂列第二、差南云八分。小野寺赢女子游泳。

| 项目 | 规则 |
| --- | --- |
| 基本移动 | 岛屿分100格，首尾日各3次，其余每日4次；时段7—9、9—11、13—15、15—17。抵达每人1分，全组无人退出并全员到达，才有前三顺序奖10、5、3分，以最后到者计时。通知时已在区内则无顺序奖。 |
| 连续遗漏 | 全组连续三次无人到达开始扣1分，第四次扣2、第五次扣3，继续递增；任一人按时到达即中止累计。 |
| 目的地与行程 | 每组同一行程，预设12种。通常每日3次在规定邻近范围、1次随机，随机不连发；首尾日无随机。课堂原文以“前一天最后指定区域”为邻近基准，具体现场路线仍逐次记录。 |
| 课题 | 通常7—17点，首日10点起、末日15点止；学力40%、身体30%、其他30%。 |
| 扩大队伍 | 第4天起部分课题可增人数上限，前三分别加3、2、1；已有6人上限者不能再参加这类课题。估计全体仅两三成队伍可取得资格。 |
| 合并 | 主方与另一组启动连结、接触手表约10秒，期间可取消；之后行程统一，两组原分数取平均。已退出者仍占原有成员名额。 |
| 退出 | 全组成员退出则得分作废、确定名次。倒数五组退学与个人点数救济沿前卷规定；目前没有最终名单。 |
| 健康手表 | 学校通过手表看健康与位置；强拆、损坏或故障会停止计分，须回起点处理。异常先警告，持续则转警报，24小时内须体检；警报5分钟不关闭，医疗人员按GPS前往。 |
| 购物与补给 | 每人5000购物点，领先卡多2500；登岛前可买至早6点，开考后起点双倍价。厕所、淋浴及必要卫生用品免费，第2天起补水点的水须当场喝完。物资允许自愿转让，男女不能同帐。 |
| 平板 | 可看自己的位置、目的地、课题；第4—12天公开前后十组与自身成绩。第6天起每次GPS查询花1点考试分，起点与指定地点可充电。 |

月城另外表示容忍一定程度的偶发争执，真嶋当场反对；恶意伤害、掠夺等并没有因此获得许可。小宫、木下受伤案中，证词与校方记录仍有未解之处。

卷末仍在第七天，班级仍称二年D班，没有最终班点、个人奖励或正式换班号公告。
