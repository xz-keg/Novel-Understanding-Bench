# 一年C班（原D班）｜一年级第十一卷

教室只剩三十九张桌子，山内的离开没有随着投票结束而过去。池、须藤沉默，平田拒绝参与，清隆得到的赞美票又引起怀疑。铃音公开承担自己指名山内的决定，清隆则自愿成为指挥塔。

接下来的考试要求每班提出十个不同人数的项目，实际各选五个，再从双方共十项中抽七项比赛。所有人先参加一次以前，同一人不能重复出场。每项胜负在两班间转移三十班点，总胜另奖一百；指挥塔败北会退学，保护点可以抵消。

铃音收集每个人的特长、安排人数和阵容。小美继续关心平田，惠、栉田也各自帮忙，幸村则私下尝试接触葛城。平田终于道歉回来后，班级重新有了能一起准备的状态，却没有因此消除所有分歧。

| 项目 | C班表现 | 结果 |
| --- | --- | --- |
| 篮球 | 须藤下半场上场，团队24比16 | 胜 |
| 打字 | 外村90分，对手吉田83分 | 胜 |
| 英语 | 八人总分443，对方651 | 负 |
| 数学 | 七人总分631，对方655 | 负 |
| 快速心算 | 松下得到指挥协助，高圆寺交白卷；葛城总计答对八题 | 负 |
| 弓道 | 明人奋战帮助全队追平，个人数据未给 | 胜 |
| 西洋棋 | 铃音先对桥本，随后双方指挥塔介入 | 正式判负 |

总比分三比四，班级净减三十点，从三百七十七变成三百四十七；清隆以保护点抵消退学。月城后来私下承认换掉棋步，没有改写公布结果。原D班赢B班五比二，按本卷规则和期初数值将升到五百零八，超过本班，清隆也已注意到又要回D班的现实。

卷尾的便当日、购物和屋顶次日等故事发生在更早时期，保留的是同学们原先怎样相处，并不是这场考试之后接连开展的新活动。
