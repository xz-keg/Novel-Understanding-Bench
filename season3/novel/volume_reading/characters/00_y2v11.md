| 人物 | 本卷经历 |
| --- | --- |
| [绫小路清隆](ayanokouji/y2v11.md) | 他参加了全部十九场体验比赛，也帮堀北和伊吹训练、替山村安排与坂柳见面。实际帮助、施加压力的手段和他对自己的解释，需要分别来看。 |
| [桥本正义](hashimoto/y2v11.md) | 背叛后的桥本一面寻求清隆帮助，一面尽力把合宿小组带好。他会调动气氛、阻止争执，也会因摸不清坂柳的反应而越来越不安。 |
| [椎名日和](hiyori/y2v11.md) | 她享受与清隆和朋友们相处，也主动照顾沉默的山村。手工、邀请、发现朋友不见后求助，都让她自己的爱好与选择变得具体。 |
| [堀北铃音](horikita/y2v11.md) | 她主动请清隆指导，和伊吹练习配合，又在返校后与清隆说笑、追问真话。她愿意承认差距，也仍会怀疑他没有说全。 |
| [坂柳有栖](sakayanagi/y2v11.md) | 神室离开以后，她承认受伤，却还不知道怎样面对山村。清隆安排了一次见面的机会，随后她重新与龙园谈判，把年末胜负正式押上自己的学籍。 |
| [山村美纪](yamamura/y2v11.md) | 她终于把抽签后的委屈说了出来：害怕自己只是随时可以被丢掉的人，却仍想知道坂柳的真实想法，也希望坂柳能赢。 |
| [南云雅](nagumo/y2v11.md) | 他用合宿完成了与清隆的私人赌局，承认输掉赌约并付款，自己的小组则夺冠。临毕业前，他仍想与学和清隆竞争，也认真发出了同校升学的邀请。 |
| [天泽一夏](amasawa/y2v11.md) | 她表面仍爱挑衅和玩笑，实际上因八神退学准备向南云发泄。清隆托南云带来的口信使她收手。 |
| [森下蓝](morishita/y2v11.md) | 她想查清桥本与清隆的关系，也认真享受自己的第一次牌局。她会观察、会恶作剧，有将棋实绩，射箭却连连失手，并非每次自信都靠得住。 |
| [鬼龙院枫花](kiryuin/y2v11.md) | 她当上组长，却把很多日常协调交给桥本，更想近看清隆与南云的比赛。谈到未来时，她能说出向往，也清楚区分向往与已经决定要走的路。 |
| [高圆寺六助](koenji/y2v11.md) | 他把交流会当成自己的休息时间，拒绝组长与清隆的劝说。看出清隆离班后的顾虑。 |
| [伊吹澪](ibuki/y2v11.md) | 她想找天泽打回去，也不想让堀北抢先。嘴上始终不服，行动上却参加了共同训练，并与堀北一起接受了二打一的实战。 |
| [栉田桔梗](kushida/y2v11.md) | 合宿让她厌烦时时保持好脸色，她会向清隆抱怨，也把堀北和伊吹当成能发牢骚的人。 |
| [龙园翔](ryuuen/y2v11.md) | 他为年末与坂柳交手做准备，甚至殴打想帮助坂柳的时任。最后，他与坂柳在老师见证下正式约定，败者自愿退学。 |
| [时任裕也](tokito/y2v11.md) | 他想让因朋友退学而低落的坂柳好过一点，因此违背龙园的命令。即使遭到殴打和威胁，他也没有答应服从。 |
| [宇都宫陆](utomiya/y2v11.md) | 他担心宝泉会伤到时任，跟来却发现龙园正在施暴，于是直接上前要求放人。他保护组员，也会因愤怒准备打架，并非一直把局面控制得很稳。 |
| [宝泉和臣](hosen/y2v11.md) | 他找到了被龙园压制的时任，借催买饮料打断，又把冲突推向打架。他的介入确实帮了时任，但并没有因此与宇都宫和解。 |
| [茶柱佐枝](chabashira/y2v11.md) | 她认真询问学生的生活和未来，也为过去对清隆的做法道歉。面对自己不了解的家庭情况，她能传达安排、表达关心，却还没有答案。 |
| [朝比奈荠](asahina/y2v11.md) | 她与南云亲近，却会当面反对他的说法，也关心清隆是否愿意接受赌局。谈大学和梦想时，她有自己的现实顾虑与好奇。 |
| [绫小路笃臣](ayanokouji_father/y2v11.md) | 茶柱确认他把三方面谈从派代理改为亲自出席，并要求得知全班日程变化。本卷只到这项安排，来校目的仍未揭晓。 |
| [堀北班（原D班）](class_d/y2v11.md) | 本卷明确称二年B班。跨班交流会没有班级点数增减，同学各自的比赛与相处不能合并成一次班级考试成绩。 |
| [阿尔伯特](albert/y2v11.md) | 他按龙园要求挡住宝泉，接下对方一拳；事后对拳力的评价，只是这次短暂交手带来的感受。 |
| [石崎大地](ishizaki/y2v11.md) | 他帮龙园把时任叫到僻静处，却漏算室友会知道去向。事态扩大后，他试图拦人，反而被宝泉挡住。 |
| [井之头心](inogashira/y2v11.md) | 她因高圆寺不听指挥而为难，向清隆求助未果；随后在自己熟悉的拼布项目中赢了清隆。两件事都该留在她的经历里。 |
| [轻井泽惠](kei/y2v11.md) | 她仍与清隆约饭、同行、计划看电影，同时坦白自己对一之濑仍有害怕。别人尚未实施的想法，不能代替她此时真实的生活。 |
| [一之濑帆波](ichinose/y2v11.md) | 她没有参加这次交流会。 |
| [石上京](ishigami/y2v11.md) | 本卷只提到他缺席交流会，未展示缺席期间的行动。 |
| [神室真澄](kamuro/y2v11.md) | 她没有在本卷重新出场。留下的人仍在承受她退学的后果，尤其是坂柳的失落与山村对那次抽签的伤心。 |
| [鬼头隼](kito/y2v11.md) | 他更警惕坂柳身边的接触，天泽伸手时立即挡住并抓住手腕。别人的担忧不能直接写成他已经报复桥本或龙园。 |
| [真岛老师](majima/y2v11.md) | 他起初不知道被坂柳叫来做什么，听懂败者退学的赌约后，认真警告双方将承担的后果。 |
| [坂上老师](sakagami/y2v11.md) | 他随龙园到场，听取退学赌约，并先问坂柳已有保护点应怎样处理。 |
| [真田康生](sanada/y2v11.md) | 他关心的不只是坂柳，也会询问被怀疑的桥本是否还好、森下和山村能否融入小组。关心同学与他自己的恋爱生活并不冲突。 |
| [宫同学（一年B班）](miya_year1b/y2v11.md) | 她来找男友真田，也向旁边的清隆打招呼。本卷没有给出她的名字或更多个人经历。 |
| [七濑翼](nanase/y2v11.md) | 她在首场插花比赛中作为对手组的选手出场，与清隆简短交谈。她个人输赢没有被点名说明。 |
| [佐藤麻耶](sato/y2v11.md) | 她认真想在交流会拿到奖励，输掉比赛后会懊恼，也担心队友泄气。与小野寺的不和没有自动消失。 |
| [馆林（三年D班）](tatebayashi/y2v11.md) | 他想带组争取奖励，却把高圆寺不合作带来的压力转向组员，最后气得准备动手，被桥本拦住。 |
| [椿樱子](tsubaki/y2v11.md) | 她与清隆同组，最后一天特意找他谈被隐瞒的家人与失散的姐姐。她想问什么尚未说完，不能提前替姐姐确定身份。 |
| [八神拓也](yagami/y2v11.md) | 他没有重新出场。天泽把他的退学说成迁怒南云的原因，并以姐弟形容两人的关系。 |

## 其他人物的补充

- [本堂辽太郎](bondo/index.md)：车上他帮忙向后排传资料，后来与坂柳同组。清隆考虑间接打听坂柳近况，却认为他和筱原口风不紧、不擅掩饰，没有向两人询问。这是清隆的评价。
- [小野寺](onodera/index.md)：她在南皮组。佐藤的小组输了那场，提到对手组时有些尴尬，清隆想到两人关系不好。没有两人个人对战的明确记录，也没有新的恋爱或和解结果。
- [平田洋介](hirata/index.md)：他在南云组。井之头求清隆找高圆寺，清隆建议改找平田，她不愿麻烦他；平田本人没接受这项任务。第17场射箭，他对桥本获胜，本组最后夺冠。
- [葛城康平](katsuragi/index.md)：他在南云组，认真练习不熟悉的项目。栉田提到他反复排队学玻璃工艺，桥本查到他射箭练习最高36环；第17场实际37环，胜过森下。
- [神崎隆二](kanzaki/index.md)：名册确认他属于二年D班，本次加入南云组。第17场射箭对新德，结合逐组对位与全组4比1结果，可以确定他这一场获胜；具体环数没写。
- [金田悟](kaneda/index.md)：本卷分组表把他与葛城列在二年C班，一同加入南云组。名单确认出席与班号，不提供他的独立比赛战绩或私下调查。
- [筱原皋月](shinohara/index.md)：她与本堂、坂柳同组。清隆想到可以向两人打听，却认为口风和掩饰能力不适合，放弃这条途径。她没有因此实际泄露消息，也没有在场接受这番评价。
- [西村龙子](nishimura/index.md)：她与清隆同属鬼龙院第20组，名册列为二年B班。本卷没有独立发言或具体个人成绩。
- [小田拓海](oda/index.md)：他在鬼龙院第20组，名册列为二年C班。首夜他参与男生房里的谈话，说南云组像夺冠热门，也思考坂柳组为何已经输了三场；后来仍与桥本和后辈一起聊天。
- [园田（堀北班）](sonoda/index.md)：车上听到分组并未按OAA均衡，园田问这样是否公平，茶柱解释游戏结果不一定由普通能力高低决定。这里仅称姓氏，按本班语境记录，与龙园班园田正志分开。
- [鬼岛](kijima/index.md)：鬼龙院与朝比奈谈梦想时，称赞现任首相鬼岛，说自己从小见过与亲属有关的政客，少数值得憧憬，鬼岛是其中之一。朝比奈确认是总理，她点头。
- [高桥修](takahashi/index.md)：他在南云组，出现在清隆首场插花比赛旁，此后几场也跟着。清隆判断他是来确认个人胜负，赛后又把他列为南云组观察比赛的成员；具体收到什么命令、知悉赌局多少，没有本人说明。
- [须藤健](sudo/index.md)：第四天晨间闲聊中，清隆提到他喜欢堀北，伊吹拿他的头脑与实力开玩笑，堀北立刻说他现在比伊吹聪明许多。这是同学对其进步的认可；须藤本人不在场。
- [堀北学](manabu/index.md)：朝比奈说南云想考的大学有堀北学，南云否认只是追着他选校。清隆承认曾受学所托观察南云；堀北也说哥哥对清隆的认可，成为自己努力的支持。南云临别还说要先去找学再比一轮。
- [池宽治](ike/index.md)：巴士上，他对南云组聚集优秀学生感到惊讶。首场对手第9组有他和启诚，但这场十名实际插花选手只有清隆一名男生。
- [幸村辉彦（启诚）](yukimura/index.md)：他与池在首轮对手第9组。此前关于把A班特权留到就业的想法，在清隆听南云谈升学时被回想。
- [月城](tsukishiro/index.md)：到凌晨食堂的第三人称场景，叙述才明确她曾从月城获得详情、装作不知以掩饰接近南云的目的。月城本人没有在合宿出现。
