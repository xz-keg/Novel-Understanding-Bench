| 人物 | 本卷经历 |
| --- | --- |
| [绫小路清隆](ayanokouji/y2v8.md) | 北海道旅行让他接触到同学平时不显露的一面。他会帮忙、试探、干预，也会看错别人的选择；他对这些行为的解释，需要与实际经过一起读。 |
| [堀北铃音](horikita/y2v8.md) | 她认真回应须藤的告白，也坚持自己的感情不能由别人替她安排。与栉田能合作、能替她保密，仍不妨碍两人私下斗气。 |
| [栉田桔梗](kushida/y2v8.md) | 她开始尝到不用时刻维持完美形象的轻松，却仍担心旧秘密被拿来控制自己。她主动找龙园交涉，受清隆帮助后又出现连自己都不愿承认的动摇。 |
| [山村美纪](yamamura/y2v8.md) | 她总怕给人添麻烦，甚至觉得借来的手套会被自己弄脏。这次旅行里，多位同伴持续留意她，她开始主动说话、开玩笑，也愿意承认自己玩得有些开心。 |
| [须藤健](sudo/y2v8.md) | 他终于向堀北正式告白，被拒绝后仍承认喜欢，却开始把学习和未来重新放回自己手上。 |
| [龙园翔](ryuuen/y2v8.md) | 他在旅行里频繁挑起摩擦，也会替受欺负的同组女生出头。 |
| [轻井泽惠](kei/y2v8.md) | 她期待旅行里与清隆相处，也会因被冷落、联系不上而生气。她自己的愿望和判断，不应全部被改写成清隆的教学成果。 |
| [一之濑帆波](ichinose/y2v8.md) | 她终于说出自己带班方式走不下去的痛苦，也承认想改变。与此同时，她仍喜欢清隆、顾虑惠，雪夜接受依靠的过程没有消除这些矛盾。 |
| [七濑翼](nanase/y2v8.md) | 她说希望清隆留校毕业，也持续提防天泽；清隆却从她对旅行风险的反应追问起她的来历。她没有承认他提出的整套推理。 |
| [天泽一夏](amasawa/y2v8.md) | 她没有随八神一起退学，却还在消化那场失败。她想继续留校，也只愿意对清隆作出特别让步。 |
| [石上京](ishigami/y2v8.md) | 这一卷终于把旧电话男声和体育祭门外访客与他的名字对应起来。他说暂时无意对清隆动手，同时保留了服从清隆父亲命令的条件。 |
| [神崎隆二](kanzaki/y2v8.md) | 他回想起小时候只会判断对错、却没有伸手制止的经历。如今他想改变班级，也因父辈旧识与补习班经历，为清隆提供了石上的线索。 |
| [坂柳有栖](sakayanagi/y2v8.md) | 她在旅行中接近龙园班的时任，也主动替清隆追查匿名访客。 |
| [西野武子](nishino/y2v8.md) | 她敢反驳龙园，也会实际照顾不熟悉的组员。她的直率不是抽象的反权威性格，而是一次次说出不愿接受的安排、站到需要帮助的人身边。 |
| [渡边纪仁](watanabe/y2v8.md) | 他想借旅行认识女生、练习与人相处，却常在强势同伴面前退让。听见鬼头认真谈未来，他也开始感到跨班竞争会伤到具体的人。 |
| [网仓麻子](amikura/y2v8.md) | 她积极与同组女生亲近，也顾虑不擅滑雪的人怎样一起玩。朋友不见时，她会直接去找人，而不只是留在聊天中的活跃气氛。 |
| [鬼头隼](kito/y2v8.md) | 他常以瞪视、较劲回应龙园，也会认真反对别人被当仆人使唤。夜谈里，他终于说出想当服装设计师的愿望。 |
| [茶柱佐枝](chabashira/y2v8.md) | 她把旅行规则交代得具体，也仍会被清隆的恶作剧惹怒。面对知惠的讥讽，她开始更坦然地接受班里已有的力量，并反省自己过去的退缩。 |
| [星之宫知惠](hoshinomiya/y2v8.md) | 她在休息时把对班级竞争的不平说到清隆面前。茶柱反复制止，她仍用鬼牌比喻表达怨气，最后以醉了为由离开。 |
| [平田洋介](hirata/y2v8.md) | 他愿意了解其他班，也坦言越理解对手，可能越难亲手阻断别人的愿望。他仍会把这种关心落实为照顾相处与组织大家玩。 |
| [佐藤麻耶](sato/y2v8.md) | 她仍喜欢清隆，却选择拒绝另一人的认真告白，也不愿妨碍惠。她的遗憾与体谅同时存在，没有被一次朋友和解抹掉。 |
| [伊吹澪](ibuki/y2v8.md) | 她还是一见堀北就想分个高下。浴场的比赛被拒绝，雪仗却终于让她赢下一场明确判决。 |
| [堀北班](class_d/y2v8.md) | 升到B班以后，同学在考试中继续进步，也被分散到跨班小组共同旅行。旧小组的裂痕仍在，班级日常却没有因此停住。 |
| [石崎大地](ishizaki/y2v8.md) | 他一面参与龙园的集会，一面很自然地拉清隆同桌吃饭。对龙园的服从是他自己的选择，西野并不接受他把这份选择推给别人。 |
| [葛城康平](katsuragi/y2v8.md) | 面对旧班同学阻断别人接近，他仍清楚表明自己愿与现在的班级共进退。转班不再只是花点数完成的手续，也已有他的立场。 |
| [桥本正义](hashimoto/y2v8.md) | 与高圆寺同组后，他亲自尝到行程被一人牵着走的麻烦，向清隆求一个办法。 |
| [高圆寺六助](koenji/y2v8.md) | 他的能力仍被清隆看重，旅行里却继续按自己的兴致走，让同组人承担配合的麻烦。 |
| [八神拓也](yagami/y2v8.md) | 他已经退学，本卷留下的是同学的追问和天泽的失落。几个人各自知道一部分。 |
| [月城](tsukishiro/y2v8.md) | 他本人没有出现，清隆却开始怀疑过去对退学行动的整个理解。这个怀疑很强，仍没有得到月城或七濑的确认。 |
| [绫小路的父亲](ayanokouji_father/y2v8.md) | 他没有到场，却从神崎的旧识和石上的电话里显出与学生家庭的联系。别人的仰慕与服从声明，还不是他亲自公开了计划。 |
| [松雄及荣一郎](matsuo/y2v8.md) | 父子的遭遇在七濑被追问时再次被提起。清隆怀疑故事可能经过设计，七濑仍坚持自己的经历真实。 |
| [司马老师](shiba/y2v8.md) | 他只在一之濑回忆无人岛偷听时被提到，本卷没有亲自出场。 |
| [坂柳理事长](chairman_sakayanagi/y2v8.md) | 他只出现在清隆关于父辈如何相识的推想中，没有到场安排一场新的会面。 |
| [姬野由贵](himeno/y2v8.md) | 前卷与神崎决定尝试改变班级之后，她在本卷只被简短提及，具体行动还没有展开。 |
| [长谷部波琉加](hasebe/y2v8.md) | 她已经能与同伴重新谈笑同行，清隆却没有走回这个小组。日常在继续，旧关系没有简单恢复原状。 |
| [三宅明人](miyake/y2v8.md) | 他没有离校，仍与朋友继续生活；这次旅行又与惠同组，但个人经历没有展开。 |
| [幸村辉彦／启诚](yukimura/y2v8.md) | 他在期末仍保持优秀成绩，与堀北并列第一。朋友关系开始继续往前走，清隆对他教法的评价却不能代替他自己的努力。 |
| [佐仓爱里](sakura/y2v8.md) | 她已经离校，仍影响留下的人怎样相处、怎样看待成绩，但本卷没有她的新行动。 |
| [小野寺](onodera/y2v8.md) | 须藤开始认真意识到她的接近，自己在本卷却没有正式告白。她在雪仗场为他应援，关系仍须由两人接下来怎样相处决定。 |
| [本堂辽太郎](bondo/y2v8.md) | 成绩仍在班级末位，却已高过退学线；遇到不懂的规则和词语，他会直接问出来。 |
| [池宽治](ike/y2v8.md) | 他盼着和熟人、女友一起玩，对跨班固定分组直接表示不满。旅行的限制对他首先是很具体的相处时间问题。 |
| [筱原皋月](shinohara/y2v8.md) | 她以池的女友被提到，本卷没有自己的独立旅行场景。 |
| [椎名日和](hiyori/y2v8.md) | 她在滑雪场远处向清隆挥手，书友关系继续存在，但本卷没有新的私下邀约。 |
| [金田悟](kaneda/y2v8.md) | 他在高级雪道与石崎、近藤一起围着龙园谈话，谈话内容没有向读者公开。 |
| [近藤](kondo/y2v8.md) | 他在高级雪道与龙园班同学一起谈话，除此以外没有展开个人经历。 |
| [阿尔伯特](albert/y2v8.md) | 他在饭桌上安静文雅，在雪仗里却灵活地躲球、接连打中对手。 |
| [的场](matoba/y2v8.md) | 他反复挡住想接近葛城的人，却没有说明是谁让他这样做。 |
| [小田](oda/y2v8.md) | 他注意到葛城独自用餐，想靠近，却被的场带开。 |
| [神室真澄](kamuro/y2v8.md) | 她在本卷只被清隆谈到，没有新的出场行动。 |
| [时任裕也](tokito/y2v8.md) | 他在第四组与坂柳同行，谨慎扶起滑倒的她，也持续与她聊天。 |
| [诸藤梨花](morofuji/y2v8.md) | 她是第四组的龙园班成员，本卷只交代了这个同行安排。 |
| [松下千秋](matsushita/y2v8.md) | 她与平田被分到同一个旅行小组，本卷没有进一步展开她的活动。 |
| [冲谷](okitani/y2v8.md) | 他与佐藤在同一个旅行小组，这是一处简短的分组说明。 |
| [王美雨](wang_meiyu/y2v8.md) | 她所在的第十五组观光超时，第四天因此留在旅馆参加学习会。 |
| [宫本苍太](miyamoto/y2v8.md) | 他与王美雨所在的小组没赶上时限，第四天要参加学习会。 |
| [矢野小春](yano/y2v8.md) | 她在雪仗中击中了正在做雪球的山村，帮助自己的队伍减少一名对手。 |
| [中西](nakanishi/y2v8.md) | 雪仗中，中西正在选目标时被清隆打中，退出了比赛。 |
| [野村雄二](nomura/y2v8.md) | 他认真向佐藤告白，遭拒以后仍表示可以再一起玩。读者听到的大部分经过，来自佐藤事后的转述。 |
| [六角百惠](rokukaku/y2v8.md) | 她在露天浴池与栉田闲谈，先行离开后，才发生栉田与堀北的私下交锋。 |
| [安藤纱代](ando_sayo/y2v8.md) | 她在短篇中叫住一之濑，只有一个很短的出场。 |
| [真岛老师](majima/y2v8.md) | 他负责旅行中的一号巴士与前五个小组，本卷没有新的私下交涉。 |
| [坂上老师](sakagami/y2v8.md) | 他负责三号巴士，到了北海道以后照看第十一至第十五组。 |
| [高桥修](takahashi/y2v8.md) | 坂柳提到，经由他与石上保持联系；他本人没有参加这次谈话。 |
| [直江原干事长](naoe/y2v8.md) | 小说中的电视快讯宣布他在东京医院去世，学生们只看了新闻的开头。 |
| [鬼岛首相](kijima/y2v8.md) | 他在直江讣告后的电视画面里简短出现，谈话刚开始就被关掉了。 |
