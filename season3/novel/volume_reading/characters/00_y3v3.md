| [绫小路清隆](ayanokouji/y3v3.md) | 他让C班在两次失败后主动接受D班的帮助，卷末亲口承认自己有意促成这种处境。夜袭A班、传递VIP名单和与龙园同归出局都有实际结果，但同学承担的损失、其他人的判断和偶发风险不能被他的事后解释抹去。 |

| [龙园翔](ryuuen/y3v3.md) | 他用开局奇袭重创C班，也能在清隆仍存活时主动停追。可终局他仍选择与清隆分胜负，舍弃更直接攻击VIP的办法，最后两人同时出局，他承认自己的执着付出了代价。 |
| [一之濑帆波](ichinose/y3v3.md) | 她留在总部做D班司令，先看出龙园的突袭迹象，又主动为受创的C班准备接纳。她把同盟指挥交给清隆，同班同学的实际配合也使合作成立；六月购物短篇则保留了她主动邀约的日常。 |
| [桥本正义](hashimoto/y3v3.md) | 他在失败后调节气氛、取物资、陪清隆冒险谈合作，也会反对时机、继续追问。终局他用清隆的话题扰乱平田，仍在交火中败下阵来，并受到对方近距离举枪的威胁。 |
| [山村美纪](yamamura/y3v3.md) | 她害怕掉队，也终于对清隆提出了真正的疑问：为什么不早些重谈同盟，或许森下就不必出局。清隆的回答没有让她安心；她仍继续护住VIP，成为C班最后留下的护卫。 |
| [森下蓝](morishita/y3v3.md) | 她提出物资意见、拒绝当司令，坚持要做护卫，却很快显出体力与射击上的困难。撤退时她想拿山村挡弹失败，随后把自己出局说成舍身相救。 |
| [椎名日和](hiyori/y3v3.md) | 她仍想见清隆，却担心感情妨碍班级。海边与龙园谈话时，她主动提醒胜负可能反转，并回答若为重要的B班，今后艰难的选择也不会逃避。 |
| [白石飞鸟](shiraishi/y3v3.md) | 她自愿担任VIP，持续传递情报，危机中仍说相信清隆。她在帐篷里向帆足承认有喜欢的人、喜欢难以读懂的声音；这些私下话没有告诉清隆。 |
| [轻井泽惠](kei/y3v3.md) | 她一边支持堀北判断两班合作，一边追问对方为什么在清隆的话题上动摇。她仍承认自己喜欢清隆，也没有把帆波与他的关系草率认定为正式交往。 |
| [须藤健](sudo/y3v3.md) | 他警戒清隆可能逆转，也支持堀北继续做能做的事。最终混战中，他连续击倒对手并救下佐藤。 |
| [平田洋介](hirata/y3v3.md) | 他帮助A班选择稳妥路线、处理规则风险，终局又实际击败桥本。胜负已定后，他把枪近指已出局者额头，最后才停手； |
| [高圆寺六助](koenji/y3v3.md) | 他脱队在岛上活动，遇到B班小队后独自击倒九名护卫，却放过VIP诸藤，让她带物资回去，随后自己退出考试。战果有利于A班。 |
| [葛城康平](katsuragi/y3v3.md) | 他整理战果、安排接人、反复提醒资源与追击风险，也在终局组织保护VIP。他没有参加最后的海边对决。 |
| [神崎隆二](kanzaki/y3v3.md) | 他在D班野外队伍中组织物资、照应同学，也当面审视清隆的合作理由。接受帆波交出同盟指挥的决定，并没有让他停止思考和提问。 |
| [堀北班整体（3-A）](class_d/y3v3.md) | 班级前期避战、保存人数，最后仍在夜袭与三班集火中失去优势。三名VIP全部出局后，A班被判全灭；本卷没有正式公布最终点数和保护点的使用者。 |
| [别府良太](beppu/y3v3.md) | 他作为D班VIP留到终盘，虽然已经疲惫，仍陪清隆前进并报告敌人位置，接敌前及时撤开。 |
| [本堂](bondo/y3v3.md) | 他在夜袭中喊开火，后来又想赶走、包围清隆，几次被同伴提醒规则。他并不是那四名违规出局者中的已确认一员，次晨仍有实际行动。 |
| [姬野由贵](himeno/y3v3.md) | 她在终盘仍是D班VIP，随神崎等人会合，再留在后方等待。没有新的改革发言或恋爱进展，不能用少台词代替她的全部立场。 |
| [帆足](hoashi/y3v3.md) | 她与白石同住双人帐篷，主动问起喜欢的人；清隆来叫白石时，她拿夜间见面打趣，回来又惊讶谈得这么快。 |
| [伊吹澪](ibuki/y3v3.md) | 她在混战中一心想打倒堀北，还拉石崎作掩护。对最后的胜负，她却主张先打VIP，龙园不采纳，战后才承认她的判断更接近取胜。 |
| [池宽治](ike/y3v3.md) | 他先笑清隆被龙园打败，后来又兴奋地以为自己亲手打倒了清隆，却因命中时已过十八点而违规出局。 |
| [石崎大地](ishizaki/y3v3.md) | 他会兴奋地请求追击，也会担心同伴、提出合作办法。伊吹逼他作掩护时，他害怕又抗议，最后仍冲了出去。 |
| [金田悟](kaneda/y3v3.md) | 他在总部担任B班司令，执行GPS停止、传战况，也遭遇同一时刻只能与一名VIP通话的限制。小队没等到预警。 |
| [鬼头隼](kito/y3v3.md) | 他先追问清隆究竟是否想拿第一，突袭来临时又主动殿后反击，为同学争取时间，自己随后出局。 |
| [小桥梦](kobashi/y3v3.md) | 她担任D班VIP，接收帆波的避战和接纳指示，再叫神崎转达。她并没有先报告C班已来求援、才让帆波想到结盟。 |
| [小宫叶吾](komiya/y3v3.md) | 初日他追敌迷路，第二日带队取物资又对独行的高圆寺轻率挑衅，最先被击倒。通讯不畅加剧危险，却不能抹去他的主动选择。 |
| [近藤](kondo/y3v3.md) | 他在突袭后独自追得过深，想先打倒清隆立功，却被对方发现、一发击中胸部。警铃响后他停住，没有继续违规射击。 |
| [真岛智也](majima/y3v3.md) | 他说明生存游戏的规则、分配程序和违规处理，面对清隆预先指定自己退学的请求。卷末又由他宣布新的考试。 |
| [的场](matoba/y3v3.md) | 他反对领袖擅定退学者、也不愿仓促让出第一，后来亲自承担前线指挥。第二次失败后，他主动请求重谈同盟，承认自己的判断需要改变。 |
| [松下千秋](matsushita/y3v3.md) | 她被选为A班司令，在总部持续读GPS、执行人物特定，再通过VIP传给野外同学。这是公开承担考试职责，不能直接推成她心理上已放弃低调。 |
| [三宅明人](miyake/y3v3.md) | 他以护卫身份陪VIP王美雨离开主队，试图避免A班全灭。B班查明两人身份后，因追击成本而没有立刻分兵。 |
| [诸藤梨花](morofuji/y3v3.md) | 她是小宫队的VIP，先担忧高圆寺并试图请示，九名护卫倒下后独自面对对方，最终被放过。高圆寺让她带物资回班，没有向她索弹药。 |
| [西川亮子](nishikawa/y3v3.md) | 她自愿当VIP，在后列传话、帮助维持队伍，却在开局突袭中出局。首夜帐篷里谈到她的人是白石与帆足，她本人并不在场。 |
| [西野武子](nishino/y3v3.md) | 遭到看不见的敌人射击时，她没有一直站着，深呼吸后冲向弹道来源，却随即被击中倒下。 |
| [小野寺](onodera/y3v3.md) | 她在第三夜被清隆击中背部出局，仍立即向赶来的堀北指明敌人方向。这个动作属于她自己的应对，不只是显示别人有多强。 |
| [六角百惠](rokukaku/y3v3.md) | 她在突袭逃跑时丢了枪，向同伴道歉，随后按要求申报，并改任分析官填补中岛的空缺。 |
| [坂上数马](sakagami/y3v3.md) | 开考说明时，他配合真岛展示冲锋枪与手枪式彩弹枪，承担教师的器材说明工作。 |
| [真田康生](sanada/y3v3.md) | 他能提醒退学规则落到个人身上的压力，也实际担任分析官报物资、提出路线意见。抽签和不同建议都没有让他失去参与判断的机会。 |
| [佐藤麻耶](sato/y3v3.md) | 她是A班VIP，受到三班集中攻击时由须藤带离火线。 |
| [岛崎一庆](shimazaki/y3v3.md) | 他主动担任C班司令，初战漏掉GPS完全静止的异常，之后继续传讯、查规则和执行战术。 |
| [筱原皋月](shinohara/y3v3.md) | 她以A班分析官身份确认物资位置，夜袭后因池违规出局而怨恨清隆。她没有参与堀北与惠的私谈。 |
| [竹本](takemoto_shigeru/y3v3.md) | 他自愿当VIP，承担转话和物资小队工作，也接下清隆夜袭前后的应对安排。许多计划是经他传到总部的。 |
| [鸟羽茂](toba/y3v3.md) | 他先问VIP为什么要拿枪，理解伪装意图后亲手练习安全检查，愿意继续学。清隆称知识来自伊集院，他没法验证这套说辞。 |
| [王美雨](wang_meiyu/y3v3.md) | 她以VIP身份转达松下的情报，执行堀北的人物特定请求。最后她与三宅分开行动以防全灭，却仍在之后的战况报告里被确认出局。 |
| [山下沙希](yamashita/y3v3.md) | 她是B班VIP，初日被选入接小宫的队伍，终盘仍与龙园、伊吹一起留下。最后两人去对付清隆时，她退在后方，没有参与攻击。 |
| [矢野](yano/y3v3.md) | 她在开局突袭中与主队走散，随后被报告已经出局。正文没有逐人展示追击、命中或她的反击。 |
| [吉田健太](yoshida/y3v3.md) | 他主动提出先学枪法再行动，突袭后也会焦躁、犯错、听解释。卷末他来庆祝预计第二名，又与桥本一起察觉老师还在准备别的事情。 |
| [幸村辉彦／启诚](yukimura/y3v3.md) | 他作为A班VIP持续接收情报，混战中给须藤递满弹匣。不能开枪并没有使他退出协作，之后他仍被确认出局。 |

## 其他人物的补充

- [中西](nakanishi/index.md)：登岛后的说明中，真岛宣布三年D班中西因发烧缺席，D班以少一人的状态开始。没有另行惩罚的通知，本人也没在岛上发言；不要与上卷六角、矢野病缺混为同一次事件。
- [鬼冢](onizuka/index.md)：规则说明时，他与伊集院在A班一侧兴奋谈笑。清隆据此猜他们可能了解或玩过生存游戏，没有本人确认履历，更没有新比赛分数。
- [伊集院](ijuin/index.md)：开考时他与鬼冢兴奋交谈，清隆后来向鸟羽声称枪械知识由他教，独白却否认这件事。第三夜他腹部被彩弹击中、警铃出局，向堀北报告不知敌人数、须藤等已追去。
- [杉尾](sugio/index.md)：看见食物不足，他提出先避开A班、翻山到东北争取物资，岛崎反驳体力与刷新点不确定，他也指出留近处可能被全灭。桥本调停后暂缓讨论，没有因意见不同发生冲突。
- [田宫江美](tamiya_emi/index.md)：她赞同森下说司令重要，提议既然清隆是领袖，就由他担任。桥本提出让清隆到前线的不同方案，最后司令是岛崎，不是她的建议已获通过。
- [元土肥千佳子](motodoi_chikako/index.md)：她反对在考试刚开始时忽然公布让D第一，说明自己不是只排斥D，而是不愿舍弃有机会争胜的可能。清隆暂缓讨论后突袭发生，她腰部被彩弹击中、叫痛；个人出局的更多细节没有单独展开。
- [清水直树](shimizu_naoki/index.md)：听见清隆说本场目标是第二名，他吃惊，追问是否从一开始就这样打算。后续同盟理由才向全班说明，他没有在此同意所有隐藏安排。
- [中岛理子](nakajima_riko/index.md)：清隆任命她与真田为分析官。突袭后队伍重整，六角被改任来填她的空缺，说明原岗位已失去人员；她具体何时被谁击中未单独描写。
- [冢地志保里](tsukachi_shihori/index.md)：她在C班分工中被任命为侦察官。B班的全体GPS停止使侦察无法发现靠近的敌人；突袭后侦察位已空，具体被击过程未给。
- [森重卓郎](morishige/index.md)：开局突袭时，他在队尾，肩部中弹后还一时站着没反应过来。这个明确动作与其他无名中弹者分开，不给他补独立台词或攻击者。
- [町田浩二](machida/index.md)：C班突然受袭，鬼头先找树回击，他与其他男生也随后找到掩体、开始射击，帮助拖住追兵。
- [泽田恭美](sawada_year2a/index.md)：突袭后她与矢野、司城都没跟上主队，在森林里走散。C班因不知道隐藏的B班位置难安全接人，之后白石转报三人均已出局，具体命中者与过程未写。
- [司城大河](shiro_taiga/index.md)：他在开局突袭后与主队走散，另有矢野、泽田。岛崎可知三人位置，却难判断被隐藏的B班动向，没能安排及时救援；随后报告三人出局。
- [山胁](yamawaki/index.md)：在诸藤的小队中，他笑小宫太得意，又指出木下前日射击也很开心。木下拍他肩时，真正痛叫的是前方中弹的小宫；他察觉袭击、叫出中枪，随后自己也被击中。
- [木下美野里](kinoshita/index.md)：她嫌男生把枪战当乐趣，山胁说亲眼见她前日也很投入，她红脸承认一时冲动，拍他肩。随后被高圆寺的彩弹击中腹部，因突然而叫痛，没有独立的反击结果。
- [薮菜菜美](yabu/index.md)：高圆寺射击小宫队时，她愣在灌木旁，侧腹被彩弹命中、手表报警。人物明确，射击成绩和当时内心则未展开。
- [小田拓海](oda/index.md)：诸藤担心高圆寺接近，他想过后让她联系金田、向龙园请示，自己跟在小宫后面。交火时西野冲出，他喊等等；全队九护卫最终出局，原文没单写他的命中部位。
- [铃木英俊](suzuki_hidetoshi/index.md)：诸藤队的八名护卫已倒下时，他吃惊地看着局面。金田终于联系诸藤的同时，他肩部中弹、警铃响，成为九名被击倒护卫之一。
- [野村](nomura/index.md)：初日葛城叫他安排围绕山下的十人搜索队，他听完立即行动。终局B班从须藤侧翼突破时，须藤击中他的腹部。
- [矶山渚沙](isoyama_nagisa/index.md)：A班利用GPS停止绕后时，她在B班后列先喊出敌人在后面。警告使同伴得知方向，具体击倒、出局或后续位置没有单独记。
- [井之头心](inogashira/index.md)：三班火力集中佐藤时，她藏在稍远的大树后。须藤比较她与冲谷的方向没有同等火力，才注意VIP被特别针对；她没有在这里解释或识破情报链。
- [冲谷京介](okitani/index.md)：终局他在须藤、佐藤两侧稍远的树后藏身。这不是冲谷自己说出的推理。
