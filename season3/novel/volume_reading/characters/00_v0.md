| [绫小路笃臣](ayanokouji_father/white_room_prequel.md) | 他把白屋当成翻身的机会，也把孩子、关系与风险都纳入自己的政治野心。真正受到抛弃时，他却无法像劝别人那样平静接受代价。 |
| [美香](mika/white_room_prequel.md) | 她与笃臣有旧情，也有明白谈价的合作。她收钱生子、签约离开，临别却仍追问对方是否喜欢过自己；这些话不能全由笃臣替她解释成演技。 |
| [雪](yuki_white_room/white_room_prequel.md) | 她在白屋里会主动聊天、表达讨厌、露出笑容，也很想留在清隆身边。多年后重逢，她依然想把没说完的话告诉他，却被拒绝了。 |
| [志朗](shiro_white_room/white_room_prequel.md) | 他曾是清隆很强的对手，后来选择让自己被淘汰，去追求自由与朋友。 |
| [铃悬锻冶](suzukake/white_room_prequel.md) | 他追求解释人类能力，也愿为研究施加残酷教育。清隆的出现既使他兴奋，也让他承认自己无法解释和复制成果，最后甚至问起这个孩子能否幸福。 |
| [坂柳成守](chairman_sakayanagi/white_room_prequel.md) | 他帮助笃臣获得引荐，也亲眼看见孩子受训后提出反对。尊重一个人的能力与认同他的做法，在他这里一直不是同一件事。 |
| [白屋](white_room/white_room_prequel.md) | 它从直江的政治构想发展成笃臣维持自身野心的机构。不同研究者、出资者与孩子各有处境，第四期最残酷的课程也不能代表每一期都一样。 |
| [月城常成](tsukishiro/white_room_prequel.md) | 他从白屋筹建时就参与其中，既监视，也提供帮助，并把自己的消息与能力当作交易。他不只服务一个人的利益。 |
| [直江仁之助](naoe/white_room_prequel.md) | 他给予笃臣上升的机会，也把失败风险留给笃臣承担。自己的政治地位受到威胁时，他很快要求对方舍弃多年经营的白屋。 |
| [鸭川](kamogawa/white_room_prequel.md) | 起初他连等候与陪席的规矩都不熟，后来确实承担了选址和政治联络，也在笃臣最失势时表达了继续追随的愿望。 |
| [石田（白屋研究者）](ishida/white_room_prequel.md) | 他坚持过自己的教育主张，也对β课程犹豫，最后仍参与执行。提出VR补救、观察清隆的特殊做法，都是他的具体工作。 |
| [宗谷](soya/white_room_prequel.md) | 他失去医师资格后仍想继续研究，被笃臣看中。自己的路线输给铃悬以后，他选择参与更残酷的方向，而非坚持作伦理反对者。 |
| [田渊](tabuchi/white_room_prequel.md) | 他会为孩子的处境提出异议，也会为清隆的记忆兴奋，最后仍承担检查、记录和安排。他没有阻止制度继续运转。 |
| [石上京](ishigami/white_room_prequel.md) | 他小时候已会判断该向谁求助，也愿为了朋友承担麻烦。聪明在这场冲突里落到了具体的保护行动上。 |
| [神崎隆二](kanzaki/white_room_prequel.md) | 他以为判断谁在说谎、劝人认错就足够了。看见石上保护朋友，再听笃臣说有力量就该使用，他开始重新想自己能做什么。 |
| [坂柳有栖](sakayanagi/white_room_prequel.md) | 她幼年就对白屋里的清隆产生兴趣，也坚定地想证明天才由出生决定。这是她自己的信念，父亲并未把它当成已经解开的科学问题。 |
| [天泽社长](amasawa_father/white_room_prequel.md) | 他把白屋当成替自己处理孩子与家庭麻烦的方便场所，谈起出资和孩子的去向，都显得轻率。 |
| [天泽一夏](amasawa/white_room_prequel.md) | 前传补出了她被送入白屋的家庭背景，却没有她自己的出场或对父亲的回应。 |
| [鬼岛](kijima/white_room_prequel.md) | 他是笃臣与直江不断谈论的政治对手，却很少直接进入本卷画面。许多关于他的结论，来自其他人的评估与消息。 |
