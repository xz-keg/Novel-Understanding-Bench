| [堀北铃音](horikita/y2v9.md) | 她成为学生会长，自己招人、审议案件，也带班赢下笔试。她能承担决定，仍会为低估栉田付出难堪的代价。 |
| [一之濑帆波](ichinose/y2v9.md) | 她辞去学生会，重新选择把精力放在班级，也经历了从想放下清隆到决定继续追求的转变。她自己的选择与算计，不能被写成别人操纵下的单一结果。 |
| [轻井泽惠](kei/y2v9.md) | 她想理解清隆的工作，也希望自己的不安得到认真回应。冷战里，她仍努力学习、向朋友求助，并几次试着主动和好。 |
| [栉田桔梗](kushida/y2v9.md) | 她不愿在堀北手下做事，却也看见学生会能带来的好处。接受职位之前，她仍坚持让堀北履行下跪条件，最后成为副会长。 |
| [南云雅](nagumo/y2v9.md) | 他想用与清隆的胜负证明自己，却也要面对被自己支配的同年级学生有什么不满。退任时，他最终接受了新会长对点数用途的限制。 |
| [桐山生叶](kiriyama/y2v9.md) | 他反对南云把三年级集资用于个人对决，却选择用假命令、栽赃与伤害无关者来阻止。想保护一些同学，与让另一些同学承担代价，在他身上同时发生。 |
| [鬼龙院枫花](kiryuin/y2v9.md) | 她无法忍受被嫁祸，执意追到真正指使者；强硬使别人难以敷衍她，也让熟悉其脾气的桐山有机会利用她。 |
| [朝比奈荠](asahina/y2v9.md) | 朋友突然退学让她难过，也使她更清楚地说出对南云统治的不满。她仍承认受过他的恩惠，同时愿意帮助清隆查另一件事。 |
| [神崎隆二](kanzaki/y2v9.md) | 他找到了愿意一起改变班级的人，也必须学习怎样让他们真正开口。 |
| [姬野由贵](himeno/y2v9.md) | 她终于向同班人说出自己为什么不想继续随大流，也主动提出办法。真的开始行动以后，她才发现自己仍有许多不懂和不安。 |
| [滨口哲也](hamaguchi/y2v9.md) | 他加入神崎与姬野，想在一之濑困难时帮忙，也会提醒改革者先尊重同伴说话的机会。 |
| [网仓麻子](amikura/y2v9.md) | 她相信一之濑，也会担心朋友的感情被拿来利用。她自己同样有很久没能放下的单恋，并不是只负责别人情报的人。 |
| [渡边纪仁](watanabe/y2v9.md) | 他喜欢网仓，却在两人单独出门时紧张得说不出话；进入严肃讨论以后，又能为了同伴认真反驳神崎。 |
| [龙园翔](ryuuen/y2v9.md) | 他想用场外干扰弥补学习差距，最后却没能让一之濑班崩溃。重新试探对手以后，他不得不收回原先的轻视。 |
| [坂柳有栖](sakayanagi/y2v9.md) | 她判断这次干扰对手得不偿失，仍输给堀北班的加权得分。另一边，她想劝一之濑远离清隆，却遇到了不再接受自己安排的对手。 |
| [桥本正义](hashimoto/y2v9.md) | 他能认可坂柳的能力，却越来越难放心把自己的前途全押在A班一直领先上，于是继续寻找别的可能。 |
| [佐藤麻耶](sato/y2v9.md) | 她认真听惠讲清楚发生了什么，再站到朋友身边；面对一之濑，也由她先把惠不敢问的话问出口。 |
| [七濑翼](nanase/y2v9.md) | 她听见招募便主动报名，成为新学生会书记。认真到自己先买了笔记本，也还在学习学生会的具体做法。 |
| [天泽一夏](amasawa/y2v9.md) | 她主动来试探栉田，知道对方在人前难以发作仍不断挑弄。对堀北的学生会也有兴趣，却没有得到加入的邀请。 |
| [石上京](ishigami/y2v9.md) | 他被堀北看中，却明确说不想加入学生会，也不需要再回去考虑。面对清隆，他没有主动展开两人的私下关系。 |
| [堀北班](class_d/y2v9.md) | 同学们在加权计分的笔试里一起争取胜利，原来学力较低的人也有机会多得分。学习、顺序与规则确认共同发挥了作用。 |
| [茶柱佐枝](chabashira/y2v9.md) | 她公布规则、带班应考、宣布胜利，也让学生自己承担备考与安排。 |
| [须藤健](sudo/y2v9.md) | 他把前卷为自己学习的决定讲得更具体：就算职业篮球的路走不通，也希望未来还有选择。 |
| [平田洋介](hirata/y2v9.md) | 他既挂念清隆与旧朋友的隔阂，也认真帮助同学准备考试，提醒他们努力时别把身体耗垮。 |
| [幸村辉彦／启诚](yukimura/y2v9.md) | 他继续带同学学习，又被安排第一个应考，利用自己的学力替下一名同学辨认合适的题目。 |
| [王美雨](wang_meiyu/y2v9.md) | 她把帮助同学落实在耐心讲题与适当休息上。 |
| [园田（堀北班）](sonoda/y2v9.md) | 备考使园田很困，仍在王美雨的辅导下努力完成眼前的任务。 |
| [池宽治](ike/y2v9.md) | 他还没有像筱原那样感到明显进步，却跟着大家继续学，也会认真问学习究竟对未来有什么用。 |
| [筱原皋月](shinohara/y2v9.md) | 她主动向须藤请教，也在持续学习中感到进步，想让自己成为班级需要的一员。 |
| [高圆寺六助](koenji/y2v9.md) | 他仍不承诺认真配合，堀北于是把他放到最后，只留下两题。他接受了安排，个人答案却没被正文公布。 |
| [石崎大地](ishizaki/y2v9.md) | 他继续替龙园干扰对手，也会在撞见熟悉的清隆时显得尴尬。两种关系没有使他停止执行任务。 |
| [小宫叶吾](komiya/y2v9.md) | 他与石崎一起闯入包厢，借口想唱歌，实际是在寻找可以干扰的学习会。 |
| [阿尔伯特](albert/y2v9.md) | 他与石崎替龙园开路，使一之濑班门口聚起骚动，但没有个人交战或新的发言。 |

| [金田悟](kaneda/y2v9.md) | 他主动找上对坂柳不放心的桥本，接受对方怀疑，仍愿进行不公开的消息交换。 |
| [神室真澄](kamuro/y2v9.md) | 她在午餐时听桥本与坂柳争论，也提出一个很实际的问题：被骚扰的人换个地方学习，不就可以了吗。 |
| [鬼头隼](kito/y2v9.md) | 他在坂柳解释策略时一直听着，后来用强硬语气追问桥本是不是仍不服气。 |
| [森宁宁](mori_nene/y2v9.md) | 她是惠日常朋友中的一员，也在结业日发来一张令惠不安的照片。发送的原因仍没有解释。 |
