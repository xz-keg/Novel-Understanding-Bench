| [绫小路清隆](ayanokouji/y2v6.md) | 他把同学的求助引向堀北，自己仍在需要时介入，也借缺席牵制坂柳。班级赢了体育祭，朋友关系却没有恢复；卷末离班、成为对手的想法尚未说出口。 |
| [堀北铃音](horikita/y2v6.md) | 她为保留栉田承担后果，借伊吹帮忙见到对方，谈成返校，又主动与龙园班合作。体育祭获胜让她更相信自己的选择，但波琉加的痛苦并没有被说服。 |
| [栉田桔梗](kushida/y2v6.md) | 她从闭门不出、打算以旷课报复，转为为了自己升A而重新上学。返校后她道歉，也保留以秘密反击的威胁；她在排球比赛中招集队友并救球。 |
| [王美雨](wang_meiyu/y2v6.md) | 羞耻和对退学投票的内疚使她连续缺席，她最后自己鼓起勇气向清隆求助。返校时同学正常迎接，栉田再度靠近仍让她紧张，伤害没有立即消失。 |
| [平田洋介](hirata/y2v6.md) | 他仍在照顾受伤的同学，也坚持不能拿感情随意试错。爱里退学后，他没有恢复轻松，连自己是在变强还是变坏都无法确定。 |
| [轻井泽惠](kei/y2v6.md) | 她享受与清隆交往的日常，也会为被舍弃的可能索要保证。面对王美雨，她主动给出鼓励；面对石崎，她则清楚说出尚未原谅。 |
| [长谷部波琉加](hasebe/y2v6.md) | 她回到学校，却没有接受爱里被舍弃。她亲口向清隆和堀北追究责任，明确要报复；班级胜利没有让她放下这件事。 |
| [三宅明人](miyake/y2v6.md) | 他继续陪着波琉加，帮助她回到学校，也退出了弓道部。面对她的复仇邀请，他没有离开，却仍没有作出口头承诺。 |
| [幸村辉彦（启诚）](yukimura/y2v6.md) | 他庆幸自己留下，却没法因此要求波琉加接受爱里的退学。他仍想以学习帮助班级，原来的朋友小组却渐渐散了。 |
| [须藤健](sudo/y2v6.md) | 他接受小野寺的组队邀请，十项全胜，并在被宝泉挑衅时真正试着控制怒气。对朋友的关心也开始落实为请别人一起解决问题。 |
| [小野寺](onodera/y2v6.md) | 她主动选择须藤搭档，既看见他的努力，也敢指出他的急躁。受伤后，她用自己的失败经验帮助他稳下来，两人最终拿下男女个人第一。 |
| [伊吹澪](ibuki/y2v6.md) | 她仍嘴硬、好胜，却确实帮堀北把栉田叫出房间。约好的较量没有妨碍她在排球场上配合两人，最后把关键一球交给堀北。 |
| [茶柱佐枝](chabashira/y2v6.md) | 她处理考试后遗留的手续与缺席，也让堀北说出动摇。她愿意支撑学生，却没有替保留栉田的决定宣布正确。 |
| [佐仓爱里](sakura/y2v6.md) | 她已经离校，名字从班级名单消失。留在学校的人仍被她的退学影响，而五千点支出的具体用途尚未向读者交代。 |
| [高圆寺六助](koenji/y2v6.md) | 他为了个人奖金参加体育祭，坚持只报单人项目，十场全胜后取得第二。堀北的保护约定仍对他有吸引力，却不是永久留班的保证。 |
| [佐藤麻耶](sato/y2v6.md) | 她仍喜欢清隆，看见他与惠亲密时也会嫉妒，并为这种心情自责。有人趁机以惠退学诱惑她，本卷停在邀约，尚未写她接受。 |
| [坂柳有栖](sakayanagi/y2v6.md) | 她原想亲自指挥体育祭，最后明知清隆在引她缺席，仍选择去见他。她能看出他有更远的打算，也在房间里受到他的实际威胁。 |
| [龙园翔](ryuuen/y2v6.md) | 他接受堀北的合作，却照旧以试探和拖延争取优势。两班最后拿下前两名，合作没有让他的做法变得温和。 |
| [葛城康平](katsuragi/y2v6.md) | 他与堀北把两班合作谈成，也负责把分工落实到比赛。面对龙园的额外要求和羞辱方案，他继续直接提出反对。 |
| [南云雅](nagumo/y2v6.md) | 他想在五项比赛里与清隆正面对决，也用三人午餐向对方施压。清隆最后缺席，使他的五连胜仍无法带来想要的满足。 |
| [鬼龙院枫花](kiryuin/y2v6.md) | 她只想完成体育祭最低要求，随后看别人比赛。面对南云的失望，她直接谈起清隆，也没有被激将成认真争冠。 |
| [天泽一夏](amasawa/y2v6.md) | 她突然上门警告另一名白屋学生的危险，却没能把名字说出。体育祭中她与七濑搭档排球，从不熟悉到迅速适应，最后仍输给了堀北等人的队伍。 |
| [七濑翼](nanase/y2v6.md) | 她先与天泽搭档排球，再与宝泉对上须藤、小野寺。本卷能看到她的运动能力，却没有她对白屋或一年级私下安排的新解释。 |
| [宝泉和臣](hosen/y2v6.md) | 他在网球场上靠攻击小野寺、激怒须藤打乱对手，输球后又动手打人。须藤没有按他预想的方式还击。 |
| [石崎大地](ishizaki/y2v6.md) | 他把清隆当朋友，也终于向惠道歉；赛场上，他仍会配合龙园装受伤、拖住对手。善意与欺负人的做法在本卷同时存在。 |
| [桥本正义](hashimoto/y2v6.md) | 他想探出清隆与班级进步的关系，也在体育祭中替受阻的同学解围。对幕后安排，他提出怀疑，却没有得到完整答案。 |
| [一之濑帆波](ichinose/y2v6.md) | 她带便当到学生会室，与南云、清隆一起吃饭，始终避开清隆的目光。本卷没有给出她对这段关系的新解释。 |
| [松下千秋](matsushita/y2v6.md) | 她主动向清隆询问班级前景，也承认自己这边伤害了筱原。想把关系修好已有尝试，受伤的人却不会立即配合。 |
| [筱原皋月](shinohara/y2v6.md) | 她没有轻易接受说坏话的同学和揭露秘密的栉田，也当面反驳堀北。池与平田后来帮忙缓和争执，这份缓和仍有具体限度。 |
| [池宽治](ike/y2v6.md) | 他在朋友帮助下尝试处理筱原与女生圈的争执，后来确实出面劝她。对转班券，他也和须藤一样认真关心规则。 |
| [前园](maezono/y2v6.md) | 班级气氛恶化后，她与佐藤、松下一起暂缓女仆咖啡厅准备；她和筱原的日常交流也停了下来。 |
| [森宁宁](mori_nene/y2v6.md) | 栉田揭露坏话后，她处在与筱原冷战的一方。本卷没有她进一步说明事情经过，也没有单独的道歉场面。 |
| [山田阿尔伯特](albert/y2v6.md) | 他陪石崎替龙园挑礼物，也先留意到惠的警戒。之后的道歉和生日提议由石崎说出，他主要安静陪同。 |
| [神室真澄](kamuro/y2v6.md) | 她信任对方的判断，却没有自己的独立指挥方案。 |
| [八神拓也](yagami/y2v6.md) | 他以学生会成员的身份转达召见，也与堀北谈起体育祭。本卷这些具名行动没有把匿名来访者或天泽的警告对象直接归到他身上。 |
| [坂柳理事长](chairman_sakayanagi/y2v6.md) | 前卷提出的保护安排有了执行迹象：清隆缺席，坂柳说看见三名警卫。女儿放弃参赛去见清隆，是她自己的决定。 |
| [绫小路的父亲](ayanokouji_father/y2v6.md) | 他没有在本卷直接登场。对他可能借来宾接触清隆的担忧，影响了体育祭的缺席和安保安排。 |
| [体育祭门外的未名年轻男子](unknown_y2v6_male_visitor/y2v6.md) | 他隔门提醒清隆，即使排除月城和白屋学生，也不能安心。清隆听出他就是过去那位匿名来电者，他仍没有报姓名。 |
| [石上京：本卷尚无身份确认](ishigami/y2v6.md) | 本卷没有以石上之名出现的新行动。宿舍门外的年轻男子仍未具名。 |
| [椿樱子：本卷相关接触尚未具名](tsubaki/y2v6.md) | 旧资料把接近佐藤的一年级学生放进椿的目录，但本卷场景未报姓名，也未写佐藤答应伤害惠。 |
| [的场信二](matoba/y2v6.md) | 他与清水赶去争取乒乓球名额，却被石崎、龙园拖住。为尽快回到比赛，他最终接受了不情愿的道歉。 |
| [清水直树](shimizu_naoki/y2v6.md) | 他被石崎碰撞后又遭拖延，先愤怒反驳，后来为班级得分勉强道歉。 |
| [里中聪](satonaka_satoshi/y2v6.md) | 他向同学传来乒乓双打的报名消息，促使的场、清水改去体育馆。本人没有在这段冲突里出场。 |
| [六角百惠](rokukaku/y2v6.md) | 她答应栉田的邀请，又一起找来福山，参加跨班组成的女子排球队。A班处境不利时，她仍想争取一份贡献。 |
| [福山忍](fukuyama_shinobu/y2v6.md) | 她被栉田和六角邀入跨班排球队，在A班可能垫底的情况下继续争取贡献。 |
| [姬野由贵](himeno/y2v6.md) | 她在应援区被栉田邀进排球队，负责帮助更擅长进攻的队友，最终随队险胜。 |
| [堀北班：返校与体育祭](class_d/y2v6.md) | 三名缺席者都回来了，两班合作也换来体育祭第一。班级得分继续上升，爱里退学留下的不信任和复仇意愿仍在。 |
