| [绫小路清隆](ayanokouji/y2v5.md) | 他先保证只让持续捣乱的人退学，后来接受堀北保留栉田，转而点名爱里。他利用自己对朋友的了解完成投票，也亲手伤害了原本答应继续参加的小组。 |
| [堀北铃音](horikita/y2v5.md) | 她坚持留下栉田，承诺让对方为伤害同学负责，也接受必须另选一人退学。清隆抢先说出爱里的名字；考试后她向清隆道歉，却没能对爱里说出话。 |
| [栉田桔梗](kushida/y2v5.md) | 她想借全场一致考试排除堀北和清隆，最后却在全班面前暴露敌意并泄露同学秘密。堀北坚持让她留下，她并未因此道谢、和解或恢复与同学的信任。 |
| [佐仓爱里](sakura/y2v5.md) | 她原本想在失恋后鼓起勇气，让清隆看见自己的改变，却在当天被他点名退学。最后她拒绝波琉加替自己牺牲，亲口请求投票，笑着告别后仍在哭。 |
| [长谷部波琉加](hasebe/y2v5.md) | 她一直在帮爱里继续过日常生活，从陪她失恋、推动文化祭邀约，到自愿代她退学。最后让她投赞成的是爱里本人的请求；此后她与清隆及班级的关系已经受伤。 |
| [三宅明人](miyake/y2v5.md) | 他先举手保护爱里，却无法接受波琉加代她退学。后置独白确认，他在那一刻认清自己喜欢波琉加；到了体育祭结束当天，他又开始面对是否陪她复仇的问题。 |
| [幸村辉彦（启诚）](yukimura/y2v5.md) | 他用有说服力的理由为堀北争取到保护点，最后却不得不面对同样的利益判断怎样伤害朋友。他先保护爱里，后来承认赞成波琉加退学，考后仍无法确认自己做得对。 |
| [茶柱佐枝](chabashira/y2v5.md) | 相同的考试让她重新面对十一年前失去恋情和升A机会的往事。她在班上克制地提醒学生别留下悔恨，考后向清隆讲出完整经过，决定认真承担现在的班导职责。 |
| [轻井泽惠](kei/y2v5.md) | 她主动向全班公开恋情，也能观察气氛、判断发言时机，在考试中协助堀北。清隆面临退学指控时，她又明确把保护他放在班级名次之前。 |
| [平田洋介](hirata/y2v5.md) | 他仍想让所有人留下，时间紧迫时才接受针对持续捣乱者的退学方案。他主动成为第一个候补，也坚持把双方的话听完，没有因此变成能轻松舍弃同学的人。 |
| [一之濑帆波](ichinose/y2v5.md) | 她坚持全员留下，认为牺牲朋友换来的A班没有意义。这个选择保住了全班，也让想改变做法的神崎孤立无援；本卷没有解决两人对班级未来的分歧。 |
| [神崎隆二](kanzaki/y2v5.md) | 他公开投赞成，试图让同学正视班级下滑的处境，甚至愿意以自己退学为代价。最后他没有说服任何人，改投反对时承认的是自己无力改变班级。 |
| [龙园翔](ryuuen/y2v5.md) | 他借匿名投票找出敢反抗自己的人，又用几张事先安排的赞成票让时任误判形势。最后全班留下，时任仍不服他；葛城的劝阻也确实改变了现场的发展。 |
| [葛城康平](katsuragi/y2v5.md) | 他阻止石崎动手，也不让时任因自尊走进不利的退学决斗。他承认时任的方法错误，仍认为敢反对龙园的人值得留下，并愿意在对方有道理时支持他。 |
| [坂柳有栖](sakayanagi/y2v5.md) | 她认为当下领先的A班不值得为一百点舍弃同学，很快让全班投了反对。她安抚同学说不会放弃他们，但这句话仍服从她对局势和利益的判断。 |
| [须藤健](sudo/y2v5.md) | 他继续认真学习，也替清隆保守恋情秘密；但一遇到堀北可能退学，仍会冲动到威胁同学。进步和没有解决的问题都在本卷里出现。 |
| [池宽治](ike/y2v5.md) | 恋爱已成为他的日常，成绩却仍接近末位。退学比较中，多位朋友愿意保护他；他也当众指出清隆改变了只处理捣乱者的承诺。 |
| [高圆寺六助](koenji/y2v5.md) | 他支持把保护点给堀北，也为自己的个人点收入坚持赞成退学。堀北用有条件的补偿说动了他，最后考试走向改变，这笔月付承诺并未生效。 |
| [佐藤麻耶](sato/y2v5.md) | 她和三位女生一起把女仆咖啡厅做成了有试演、有预算的提案，也仍想先让清隆看见自己。考试后半，她能直说普通同学对被随机选中退学的担心。 |
| [王美雨](wang_meiyu/y2v5.md) | 她写出了细致的文化祭企划，却仍会为穿衣展示和喜欢的人紧张。考试中她先安抚栉田，后来自己的恋情却被栉田当众说破，这份信任受到直接伤害。 |
| [松下千秋](matsushita/y2v5.md) | 她能把文化祭点子落实为花费和展示，也能看出朋友的恋爱心思。面对退学，她公开支持按当前贡献选择爱里；与此同时，她自己也被卷入栉田的爆料。 |
| [筱原皋月](shinohara/y2v5.md) | 她与池已在认真过情侣的日常，也替想去北海道的同学赢下猜拳。栉田的爆料使她当众难堪，后来她仍明确举手保护池。 |
| [八神拓也](yagami/y2v5.md) | 他还承认，两人第一次见面时的熟识关系是自己故意装出来的。 |
| [椎名日和](hiyori/y2v5.md) | 她在龙园班的投票中参与了不易被看见的配合。具体经过主要由葛城讲出，尤其是把葛城拉进来是否出于她自己的判断，结尾仍留有疑问。 |
| [伊吹澪](ibuki/y2v5.md) | 她不相信龙园突然愿意顺从多数，被同学点名退学后，也拒绝让别人替自己决定去留。她用一票反对守住自己，承认学校里还有想做的事。 |
| [时任裕也](tokito/y2v5.md) | 他利用匿名赞成票反抗龙园，却把龙园安排的票误当成援军。葛城阻止他走向退学决斗，他最后为不连累全班改票，仍没有认可龙园的做法。 |
| [西野武子](nishino/y2v5.md) | 她敢公开说自己愿意以退学换点数，也会接受班级最后的方针。面对龙园迟迟不结束投票，她直接追问；伊吹有危险时，她却阻止石崎出头。 |
| [星之宫知惠](hoshinomiya/y2v5.md) | 她仍怨恨茶柱当年的选择，也更认同神崎对班级的忧虑。她用自己的往事追问同学能否在最后关头牺牲一人，却没能改变全班保护伙伴的决定。 |
| [堀北班（原D班）](class_d/y2v5.md) | 全场一致考试通过，班级共得一百五十点，人数从三十九减为三十八。爱里退学、栉田被留下，朋友与同学之间的伤害没有随着考试结束消失；本卷仍称C班。 |
| [山田阿尔伯特](albert/y2v5.md) | 葛城把他列为配合龙园投赞成票的人之一。本卷没有他的亲口解释。 |
| [绫小路笃臣](ayanokouji_father/y2v5.md) | 本卷没有直接出场。坂柳理事长担心他可能借来宾安排接近清隆，但没有确认他已经介入。 |
| [本堂辽太郎](bondo/y2v5.md) | 他会很快提出点子，也肯在被退回后再试一次，只是准备仍不充分。考试里他起初轻松，后来担心自己，并坚决要求清隆拿出指控栉田的证据。 |
| [坂柳理事长](chairman_sakayanagi/y2v5.md) | 他重新主动联系清隆，提出借病假和宿舍警卫减少来宾接近的风险，同时承认自己无法撤回上层已经发出的邀请。 |
| [桥本正义](hashimoto/y2v5.md) | 他参与坂柳预先安排的分票，也提醒她不要轻视一百点的价值。他提出疑虑，但没有坚持本次必须牺牲同学。 |
| [姬野由贵](himeno/y2v5.md) | 她听懂神崎的担心，却认为眼前还没有充分理由让同学退学，并直接请他停止这次抵抗。 |
| [碇老师](ikari_teacher/y2v5.md) | 负责向四班班导说明监考要求和干涉后果； |
| [石仓贺代子（堀北班）](ishikura_classmate/y2v5.md) | 她代表想去北海道的同学担任猜拳中锋，输给小野寺。这里是堀北班的石仓贺代子，与三年B班同姓的石仓分开记录。 |
| [石崎大地](ishizaki/y2v5.md) | 他习惯等龙园发指示，也会急着替龙园维护秩序。但伊吹受到退学威胁时，他想站出来保护她，说明对同学的在意并未消失。 |
| [金田悟](kaneda/y2v5.md) | 他公开赞成用退学换点数，相信自己的能力足以使龙园留下自己；等班级方针确定，又愿意改投反对。 |
| [小宫叶吾](komiya/y2v5.md) | 他试图让投赞成的人放心承认，也会在龙园不回应时紧张；在筱原那边，他的名字被栉田拿来刺激刚交往的两人。 |
| [前园](maezono/y2v5.md) | 她与佐藤等人共同出钱准备咖啡厅，负责守门、保密和催促换装，也在旅行地争论中主动为北海道队出场。 |
| [宫本](miyamoto/y2v5.md) | 他怀疑堀北所谓知道是谁，可能只是逼人改票的说法，并要求若真有对象就公开商量。这是他在信息不足时提出的解释。 |
| [森宁宁](mori_nene/y2v5.md) | 被栉田当众指称嘲笑过筱原后，她先否认，又在追问下支吾。 |
| [诸藤梨花](morofuji/y2v5.md) | 她附和薮，明确表示可以让伊吹退学，也声称自己此前都投反对。提案最后没有实现。 |
| [鬼冢同学](onizuka/y2v5.md) | 考试换座后坐在清隆前面，后来被惠指认为与本堂约好互相保护的人；本卷没有他的亲口回应。 |
| [小野寺](onodera/y2v5.md) | 她代表冲绳派猜拳，连续淘汰几名对手； |
| [坂上数马](sakagami/y2v5.md) | 负责龙园班的考试流程，也明确确认暴力会使考试中止、班级失去资格。 |
| [柴田飒](shibata/y2v5.md) | 他相信团结、保护同学能让班级最终获胜，因此很难接受神崎坚持投赞成。两人对眼前危险的判断，在争论中明显分开。 |
| [白波千寻](shiranami/y2v5.md) | 她明确反对为点数舍弃同学，认为班里没有谁是退学也无所谓的人。 |
| [月城常成](tsukishiro/y2v5.md) | 本人没有在本卷出场；理事长与清隆谈到之前的事件，八神的题型预测也明确没有来自他的泄题。 |
| [薮菜菜美](yabu/y2v5.md) | 她因为投票僵持而提出改选赞成，直接把伊吹当作可舍弃的人。伊吹拒绝配合后，这个提议没有继续实施。 |
| [矢岛麻里子](yajima_mariko/y2v5.md) | 被龙园指为来回改票的人后，她当场否认，却仍遭到退学威胁。 |
